## 一、各书的处理

### Garling, *A Course in Mathematical Analysis* II, §11.1（p. 303 / PDF 15）

开篇第一段就是我们第 1 章所铺的那条线，值得整段引用其意思：

> 虽然 R 的基本性质依赖于 R 的序结构，但我们所考察的实分析中的大多数想法与结论
> （例如数列的极限、函数的连续性）都可以用 3.1 节定义的距离 d(x,y)=|x−y| 表述。
> 距离这一概念出现在分析学的许多其他领域，这正是我们现在要研究的。

第 1 章末的对照表与「本章的核心」一节，接的正是这句话。**第 2 章开篇应当直接从
第 1 章的结论续上**：确界原理搬不过来，Cauchy 完备性搬得过来，本章就把后者所需的
最小结构单独提取出来。

**公理的写法有分歧，值得在正文中点破。** Garling 把 d 的陪域取作 R₊，
于是只列三条：对称、三角不等式、d(x,y)=0 当且仅当 x=y。Pugh 则把非负性
写进第一条（正定性）。两者等价，因为非负性可由其余条件推出：
0 = d(x,x) ≤ d(x,y) + d(y,x) = 2d(x,y)。**这个推导应当作为习题**，
它让学生第一次体会到「公理组可以有冗余」。

Garling 的例子序列（§11.1）：
1. R 与 C 的通常度量（11.1.1）
2. 欧氏度量（11.1.2），需先证 Cauchy 不等式（11.1.3，用 Lagrange 恒等式，
   是 Cauchy 1821 年的原证）
3. 扩充实直线 R̄ 上的度量（11.1.8）：用 j = arctan 把 R̄ 双射到 [−π/2, π/2]，
   再拉回度量。**这个例子很好**，它说明度量可以从别处「搬」过来
4. N ∪ {∞} 上的度量（11.1.9），同样手法，f(n)=1/n、f(∞)=0
5. 一致度量（11.1.10），定义在有界映射空间 B(S,X) 上——函数空间的第一个例子
6. 伪度量（11.1.12）：把「d=0 当且仅当 x=y」减弱为「x=y 蕴含 d=0」，
   再作商得到度量空间（11.1.13）

§11.2 赋范空间、§11.3 内积空间紧随其后。**这个顺序值得照抄**：
先度量（最弱），再范数（有线性结构），再内积（有角度）。每一步都多一点结构。

### Pugh, *Real Mathematical Analysis*, 第 2 章 §1（p. 58 / PDF 68）

面向学生的写法，可作行文参照。两处可直接借用：

- **离散度量**他的介绍语是「难以想象但作为反例来源极有价值」。
  三点集的离散度量可以想成单位正三角形的三个顶点，两两距离为 1。
  这个具体模型对新生有用，第 1 章的经验表明抽象概念必须先给可视化的实例。
- 他强调子集继承度量后成为**度量子空间**，并配图给出 R² 的若干子集。
  本讲义应当照做：子空间是后面处理紧性、连通性时反复用到的构造。

### Garling §14.6 压缩映射定理（p. 412 / PDF 124）

本章的终点。要点：

- 压缩映射定义要求存在 **0 ≤ K < 1** 使 d(f(x),f(y)) ≤ K·d(x,y)，
  即 Lipschitz 常数严格小于 1。Garling 特别强调「K 严格小于 1 这一点至关重要」。
- 证明：任取 x₀，令 xₙ₊₁ = f(xₙ)，则 d(xₙ,xₙ₊₁) ≤ Kⁿ d(x₀,x₁)，
  用等比级数估计得 d(xₘ,xₙ) ≤ Kᵐ d(x₀,x₁)/(1−K)，故为 Cauchy 列；
  完备性给出极限，连续性给出 f(x∞)=x∞；唯一性由 d(y,x∞) ≤ K d(y,x∞) 得。
- **三条附注全都该写进讲义**：
  1. 误差估计 d(x₀,x∞) ≤ d(x₀,x₁)/(1−K)——只用第一步就能框住答案，
     这是数值计算中真正用到的形式。
  2. 收敛是指数快的：d(xₙ,x∞) ≤ Kⁿ d(x₀,x∞)。
  3. **把条件减弱为 d(f(x),f(y)) < d(x,y)（x≠y）就不够了。**
     反例：f(x) = x + e⁻ˣ 在 [0,∞) 上无不动点，但由中值定理
     |f(x)−f(y)| = (1−e⁻ᶜ)|x−y| < |x−y|。
     这个反例必须进「常见错误」框——它正是学生最容易想当然的一处。


### Garling §12.1 数列收敛（p. 330 / PDF 42）

- 收敛的定义与 R 上逐字相同，只把 |aₙ − l| 换成 d(aₙ, l)。
  Garling 自陈「证明大多是卷一相应证明的显然改写」，但**呈现顺序有所不同**。
- 一处编排值得借用：他先证 **命题 12.1.1**「aₙ→l 且 bₙ→m 蕴含 d(aₙ,bₙ)→d(l,m)」
  （即 d 本身连续），再把**极限唯一性**作为推论——取 bₙ = aₙ 得 d(l,m)=0。
  比通常「反设两个极限，取 ε = d(l,m)/2」的写法干净，且顺带交代了 d 的连续性。
- 开 ε-邻域记作 N_ε(x)，收敛即「最终落进每个 N_ε(l)」。

### Garling §12.3 度量空间的拓扑（p. 342 / PDF 54）

**这一节 Garling 自己警告有混淆风险**，原话是两个定义「相似到足以令人困惑」：

- **聚点**（limit point / accumulation point）：每个去心邻域 N*_ε(b) 与 A 相交。
- **闭包点**（closure point）：每个邻域 N_ε(b) 与 A 相交。

差别只在去不去心。A 中的孤立点是闭包点但不是聚点。导集 A′ 是聚点全体，
闭包 Ā 是闭包点全体；A′ = Ā 者为完全集，A = Ā 者为闭集。
**这一对概念直接进「常见错误」框**，配孤立点的例子（如 A = {0} ∪ [1,2]）。

### Garling §14.1 完备性（p. 386 / PDF 98）

开篇一句话是本章最重要的收获：

> 收敛的一般原理在 R 上的分析中起了关键作用，类似的想法在度量空间上同样重要。
> **正如我们将看到的，这些不是拓扑的概念。**

**完备性不是拓扑性质。** R 与 (0,1) 同胚，前者完备而后者（在通常度量下）不完备。
同一个拓扑可以由完备的度量诱导，也可以由不完备的度量诱导。

这一条对第 1 章的对照表是个实质补充。第 1 章把性质分成「依赖序」与「依赖距离」两类，
现在要再分一层：**依赖距离**的性质里，有的（如开集、连续）只依赖距离所诱导的拓扑，
有的（如完备性、一致连续、有界）依赖度量本身。第 2 章须把这一层讲出来，
并回指第 1 章的表加以细化。

其余内容：
- 命题 14.1.1：(i) 收敛列是 Cauchy 列；(ii) **有收敛子列的 Cauchy 列必收敛**。
  第二条是后面证完备性时最常用的工具。
- 定理 14.1.2：Rᵈ、Cᵈ 中 Cauchy 等价于各坐标 Cauchy，故完备。

### Garling §14.5 完备化（p. 408 / PDF 120）

完备化的刻画不止「Cauchy 列都收敛」，还要加上**稠密性**：

> 从有理数域 Q 出发我们构造了实数域 R。这填上了有理数中的空隙——任何 Cauchy 列
> 都收敛——但填得很经济，因为任一实数都是有理数列的极限。

即完备化 = 完备 + 原空间稠密其中，这两条合起来才给出唯一性。
§14.5 的习题（p. 412）要求用完备化的第二种证法重新构造 Q 的完备化，
并证它是有序域且具确界性质，并注明「这是从 Q 构造 R 的另一条途径」——
**与第 1 章附录 A 的康托尔构造是同一件事**，两处应当互相引用。

### Sutherland《Introduction to Metric and Topological Spaces》第 5 章（PDF 50）

入口与 Garling 不同：**他从连续性出发**，不从完备性出发。先把 ε-δ 定义改写成
「距离」的说法，指出这套说法在 R² 上一字不改地成立，再抽象为度量空间。
第 6 章接闭集、闭包、聚点、内部、边界、收敛、**等价度量**，第 7 章才进拓扑空间。

「等价度量」这一节正是上面「完备性不是拓扑性质」所需的工具，
本章末预告卷四时应参照他的过渡写法。

> **注意**：这本 PDF 的文字层质量差（扫描后 OCR，希腊字母与数学符号大量错乱，
> 如 ε 显示为 c、ℝ² 显示为 ~2）。**不可直接复制引用，须对照图像页核对。**

### Pugh 第 2 章 §3 度量空间的拓扑（p. 65 / PDF 75）

**编排是反的，值得注意。** 他先用「保持序列收敛」定义连续，再把 ε-δ 作为
**定理 4** 证明其等价。理由是序列收敛在第 1 章已经建立，而 ε-δ 对新生是负担。
本讲义第 3 章讲连续性时可考虑这个次序。

**术语冲突（重要）。** Pugh 在脚注里明确指出本领域的一处分歧：

> S 的 limit 有时也称作 limit point。但要当心：**有些数学家要求 limit point 是
> S 中互不相同的点所成序列的极限**。按他们的观点，有限集没有 limit point。
> 我们不采用这种观点。

于是：
- **Garling 的 limit point** = 去心邻域与 A 相交 ⟹ 有限集没有聚点；
  他另设 closure point 表示不去心的情形。
- **Pugh 的 limit** = 不去心 ⟹ 相当于 Garling 的 closure point；
  他不单独设「聚点」概念。

**两本骨架书在此处不兼容。** 讲义必须选定一套并在正文中写明这个分歧，
否则学生对照两书阅读时必然出错。建议采用 Garling 的一套（聚点／闭包点分设），
因为后续讲完全集、导集、Cantor 集时需要区分，且这是国内教材的通行译法；
但要在「常见错误」框里写明 Pugh 的用法与之不同。

Pugh 同一条脚注还提到：「在更一般的情形下，极限用**网**而不是序列来定义，
网像是『不可数的序列』」。这与大纲第七节的收敛阶梯主线正好对上，
本章末的预告可以引这句话。

### Pugh 第 2 章 §10 完备化（p. 119 / PDF 129）

构造写得比 Garling 清楚，可直接作为本讲义的蓝本。

**引理 81（四点不等式）**：|d(p,q) − d(x,y)| ≤ d(p,x) + d(q,y)。
由三角不等式两次夹逼得到。这是全节的技术关键，它保证了下面的极限存在。

**构造**：取 M 中全体 Cauchy 列之集 C（收敛与否不论）。称 (pₙ) 与 (qₙ) 是
co-Cauchy 的，若 d(pₙ,qₙ) → 0；这是 C 上的等价关系。令 M̂ = C / co-Cauchy，
其元素是等价类 P = [(pₙ)]，度量定为

    D(P, Q) = lim_{n→∞} d(pₙ, qₙ)。

余下验证三件事：(a) D 是良定义的度量；(b) M ⊂ M̂；(c) M̂ 完备。
(a) 用引理 81 说明 (d(pₙ,qₙ)) 是 R 中的 Cauchy 列，由 R 完备故极限存在。

Pugh 对这个构造的评语是「这是个大胆的想法，不是吗」——把 Cauchy 列本身
当作新的点。**这正是第 1 章附录 A 康托尔构造的同一手法**，两处必须互相引用：
学生在第 1 章见过一次（从 Q 造 R），在第 2 章见到它其实是一般构造的特例。

## 二、本章的设计要点

1. **开篇动机接第 1 章**。第 1 章末尾说「能推广的只有 Cauchy 完备性」，
   第 2 章开篇就兑现：把 d 的三条性质单独拎出来当公理，看看能走多远。
   失败案例改为正面案例：在 C[a,b] 上，两个函数谁大谁小无意义，但距离有意义。

2. **例子库一次建足**，后续各章反复调用。至少要有：
   R 与 C；Rⁿ 的欧氏度量、ℓ¹ 度量、ℓ∞ 度量（三者对比，配图画单位球）；
   离散度量；C[a,b] 的一致度量；序列空间 ℓᵖ；子空间度量。
   按第 1 章的经验，**抽象定义之前先给三个已熟悉的实例**。

3. **公理冗余**作为习题：由对称性与三角不等式推出非负性。

4. **度量诱导拓扑**只讲到够用为止：开球、开集、闭集、内部、闭包。
   一般拓扑空间留到卷四。这是大纲第 2.4 节定的分寸。

5. **完备化**放在压缩映射之前还是之后？Garling 的顺序是完备化（14.5）在前、
   压缩映射（14.6）在后。本讲义拟照此，因为完备化的构造要用到 Cauchy 列的
   等价类，与第 1 章附录 A 的康托尔构造是同一手法，可以互相印证。

6. **收敛阶梯的第一级**（见 curriculum-math.md 第七节）在本章埋设：
   正文要指出度量诱导拓扑，但不是每个拓扑都来自度量，
   并预告卷四会给出反例与网/滤子。
