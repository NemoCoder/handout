## 一、四本书各自把什么当作原始概念

这是本章设计的核心问题。同样讲实数，四本书选的出发点不同，取舍值得逐一记下。

### Garling, *A Course in Mathematical Analysis* I, §3.1（p. 79 / PDF 97）

- 先在 Prologue 用 Dedekind 分割**构造**出 R，然后明说：「把构造当作已知，
  写下 R 的本质性质，用这些性质展开分析学。」构造与公理化分开，是干净的处理。
- 取**上确界性质**为基本性质，下确界性质由它推出（他给的推法是取下界集合 B，
  证 sup B = inf A，两行完事）。
- Theorem 3.1.1 把三件事一次证完：inf{1/n} = 0；阿基米德性；Q 在 R 中稠密。
  三者同源，都靠确界。这个打包方式值得抄。
- **关键的一处**（p. 81）：他在 §3.1 里就定义 d(x,y) = |x − y|，验证三条度量公理，
  然后写下「The function d is a metric on R. We shall study more general metrics
  in Volume II.」——第一章就把度量埋下，第二卷再抽象。这正是本讲义要走的路子，
  且证明了这条路子在成熟教材里已有先例。
- §3.3（p. 91 / PDF 109）证唯一性：任一具备上确界性质的有序域与 R 保序同构。
  构造法是先在 Q 上定同构，再用二进制逼近 x_n = ⌊2ⁿx⌋/2ⁿ 延拓。
  证明不难但琐碎，讲义里给结论与思路即可，完整证明留作附录或习题。
- §3.6（p. 98 / PDF 116）才引入 Cauchy 列，标题叫「收敛的一般原理」。
  他的顺序是：确界 → 单调有界 → Bolzano–Weierstrass → 上下极限 → Cauchy。
  Cauchy 排在最后，作为「不知道极限是什么时怎么判断收敛」的答案。

### Zorich, *Mathematical Analysis* I, §2.1（p. 35 / PDF 56）

- 纯公理化，不构造。四组公理：加法、乘法、序、完备性。写得极其铺陈，
  连 0 < 1 都要证（p. 43）。这个详尽程度对讲义太重，但公理的分组方式可以借鉴。
- **完备性公理取的是 Dedekind 分割形式**，不是确界形式：
  「若 X、Y 非空且对一切 x ∈ X、y ∈ Y 有 x ≤ y，则存在 c 使 x ≤ c ≤ y。」
- 确界原理在他这里是**引理**，由完备性公理推出（p. 45 / PDF 66），证明三行：
  取 Y 为 X 的全体上界，由公理得 c 夹在中间，c 既是 X 的上界又是 Y 的下界，
  故 c = min Y = sup X。
- 这个选择说明一件事：**哪一条当公理是可选的**。讲义应当把这一点讲明，
  而不是像多数中文教材那样把确界公理供起来当唯一起点。

### Amann & Escher, *Analysis* I, §I.10（p. 91 / PDF 105）

- 这本最合我们的路子。它把序完备性定义在**全序集**上，而不是有序域上：
  「A totally ordered set X is order complete if every nonempty subset
  bounded above has a supremum.」
- **Proposition 10.1** 给出三者等价：(i) 上确界性质 (ii) 下确界性质
  (iii) Dedekind 分割性质。证明是 (i)⇒(ii)⇒(iii)⇒(i) 的循环，各三五行。
  **要点是这条命题里根本没出现域运算**——三者是纯粹的序性质。
  这正是本讲义第 1.3 节应当照搬的处理：先把「与域无关的部分」剥离出来。
- **Example 10.3** 证 Q 不序完备，用的不是 √2 无理，而是直接取
  A = {x ∈ Q : x > 0, x² < 2}，B = {x ∈ Q : x > 0, x² > 2}，
  假设有 c 夹在中间，令 ξ = (2c+2)/(c+2)，算出
  ξ − c = −(c²−2)/(c+2)，ξ² − 2 = 2(c²−2)/(c+2)²，
  于是 c² < 2 时 ξ > c 且 ξ ∈ A，c² > 2 时 ξ < c 且 ξ ∈ B，两头都矛盾。
  **这个证明比「√2 是无理数」强**：它不只说少了一个数，而是直接说明
  分割性质失效，与完备性的定义正面对上。讲义应当两个都给：
  √2 无理作为动机，A/B 分割作为正式论证。
- Theorem 10.4：在同构意义下存在唯一的序完备扩域 R。他坦承构造细节「boring」，
  只给思路，另在 II.6 给 Cantor 的 Cauchy 列构造。这个态度可取。

### Rudin, *Principles*（库中是 2024 重排本，页码不可引）

- 取最小上界性质为公理，构造放第一章附录。处理最省笔墨，
  但删去了全部动机，不适合作讲义蓝本，只宜用来校准定理陈述是否啰嗦。

## 二、由此确定的本章结构

四本书的共同点是都要处理「哪条当公理」，分歧在于选哪条。本章的做法是
**把选择权本身讲出来**：先证四种刻画等价，再任选一条作为定义。

设计要点，按重要性排：

1. **把纯序性质与度量性质分开。** 上确界、下确界、Dedekind 分割三者等价，
   且只用到序（照 Amann–Escher Prop 10.1）。单调有界、闭区间套也是序陈述。
   Cauchy 完备性则只用到 d(x,y) = |x−y|，与序无关。
2. **确界原理 = 阿基米德性 + Cauchy 完备性。** 这条恒等式是本章的题眼。
   左端是序陈述，右端拆成一条序陈述加一条度量陈述。第 2 章能搬到度量空间去的
   只有 Cauchy 完备性那一半，阿基米德性搬不过去——一般度量空间里没有序。
   这就解释了为什么后续一切抽象理论里出现的是「完备度量空间」而不是「确界」。
3. **阿基米德性不是白给的。** 必须给出非阿基米德有序域的例子，否则学生会以为
   有序域自动是阿基米德的。用有理函数域 R(t)，按「首项系数为正则为正」定序，
   则 t 大于一切自然数。这个例子简单可验，放正文。
4. **Q 不完备要证两遍。** √2 无理给动机，A/B 分割给正式论证。
5. **构造放附录。** 正文只给唯一性定理的陈述与思路（Garling 3.3.1）。
