\chapter{实数系}
\label{ch:reals}

\begin{keypoint}[本章要点]
  \begin{itemize}
    \item 分析学的每一个概念都含有极限过程，而极限是存在性断言。
          有理数系中存在「本该收敛却无处可去」的数列，因此不足以承载分析学。
    \item 上确界是「最低的那块天花板」：上界是能盖住集合的天花板，
          上确界是其中最低的一块。它未必碰到集合中任何一点，
          这是初学时最容易出错的一处。
    \item 「数系没有空隙」有几种不同的精确表述，它们彼此等价，
          可任选其一作为公理。实数系即序完备的有序域，在同构意义下唯一。
    \item 这些表述所依赖的结构并不相同：确界原理依赖序，
          Cauchy 完备性只依赖距离。这一差别决定了它们各自能推广到多远。
  \end{itemize}
\end{keypoint}

\section{为什么从实数讲起}
\label{sec:why-reals}

数学分析研究的对象是极限。连续、导数、积分、级数，这些概念的定义中都含有极限过程。因此在建立分析学之前，必须先确认所用的数系能够承载极限。

考察下面的数列。逐位写出满足 \(x^{2} = 2\) 的正数的十进制近似值，得到
\begin{equation}
  \label{eq:sqrt2-decimal}
  a_{1} = 1, \quad a_{2} = 1.4, \quad a_{3} = 1.41, \quad
  a_{4} = 1.414, \quad a_{5} = 1.4142, \quad \dots
\end{equation}
每一项都是有理数；数列单调递增，且以 \(2\) 为上界；各项彼此越来越接近，
当 \(m, n \ge N\) 时 \(\abs{a_{m} - a_{n}} \le 10^{-N+1}\)，
这个上界可以任意小。就数列自身而言，它没有任何异常。

但它在 \(\Q\) 中不收敛。设其极限为有理数 \(a\)，由极限的四则运算法则
应有 \(a^{2} = 2\)，而下述古典结论表明这样的有理数不存在。

\begin{proposition}
  \label{prop:sqrt2-irrational}
  不存在有理数 \(r\) 使得 \(r^{2} = 2\)。
\end{proposition}

\begin{proof}
  反设存在既约分数 \(r = p/q\)（\(p, q \in \Z\)，\(q \neq 0\)，\(\gcd(p,q)=1\)）
  使得 \(p^{2} = 2q^{2}\)。则 \(p^{2}\) 为偶数，故 \(p\) 为偶数，
  记 \(p = 2k\)。代入得 \(4k^{2} = 2q^{2}\)，即 \(q^{2} = 2k^{2}\)，
  于是 \(q\) 亦为偶数。这与 \(\gcd(p,q) = 1\) 矛盾。
\end{proof}

问题不在数列，而在 \(\Q\)。\cref{eq:sqrt2-decimal} 的各项在 \(\Q\) 中越挨越近，共同趋向某个位置；
而 \(\Q\) 中没有数落在那个位置上（\cref{fig:q-gap}）。
打个比方。一条绳子无论从哪里剪断，剪刀总落在绳上某一点；
这一点或归左段、或归右段，总之存在。而把 \(\Q\) 从 \(\sqrt{2}\) 处剪开，
刀口上什么也没有。\term{戴德金分割}{Dedekind cut}中的「分割」二字，
说的正是这件事。

若在这样的数系上建立分析学，则无论数列的各项挨得多近，
都不能断言它有极限；而分析学的几乎每一条定理都要用到这类断言。
单调有界必收敛、闭区间上的连续函数取到最大值、Cauchy 判别法，
这些结论在 \(\Q\) 上全部不成立。

\begin{enumerate}[label=(\arabic*)]
  \item 给出「没有空隙」的精确表述。这样的表述不止一种，

\end{enumerate}

\section{预备：本章要用到的记号与事实}
\label{sec:prelim}

本章的论证会用到一些中学阶段已经接触、但尚未精确陈述的概念与事实。
本节把它们集中列出，只作约定与陈述，不展开。读者若已熟悉可直接跳到%
\cref{sec:rational-gap}；遇到不确定的记号再回来查。

\subsection*{集合与映射}

\(\N = \set{1,2,3,\dots}\)（本讲义的自然数从 \(1\) 起），\(\Z\) 为整数集，
\(\Q\) 为有理数集。集合的构造记法写作 \(\setst{x \in A}{P(x)}\)，
读作「\(A\) 中满足 \(P\) 的那些 \(x\) 所成之集」。

映射 \(f \mapsdef A \to B\) 由定义域 \(A\)、陪域 \(B\) 与对应法则确定。
对 \(S \subseteq A\)，\(f(S) = \setst{f(x)}{x \in S}\) 称为 \(S\) 的\term{像}{image}；
对 \(T \subseteq B\)，
\begin{equation}
  \label{eq:preimage}
  f^{-1}(T) = \setst{x \in A}{f(x) \in T}
\end{equation}
称为 \(T\) 的\term{原像}{preimage}。注意 \(f^{-1}(T)\) 这个记号不要求 \(f\) 可逆，
它只是「被映进 \(T\) 里的那些点」的简写。原像与并、交、补都可交换，
像则一般不然；这一差别在第 3 章刻画连续性时是关键。

\subsection*{域与全序}

\term{域}{field}指这样的集合：其上给定加法与乘法，使得加减乘除（除数非零）
都能施行且满足通常的运算律：两种运算各自结合、交换、有单位元与逆元
（加法逆元对一切元素存在，乘法逆元对非零元素存在），且乘法对加法分配。
\(\Q\) 与 \(\R\) 都是域，\(\Z\) 不是（\(2\) 没有乘法逆元）。

集合 \(X\) 上的\term{全序}{total order}是一个关系 \(\le\)，满足自反
（\(x \le x\)）、反对称（\(x \le y\) 且 \(y \le x\) 蕴含 \(x=y\)）、传递
（\(x \le y\) 且 \(y \le z\) 蕴含 \(x \le z\)），并且\emph{任意两元素可比较}：
对一切 \(x,y\) 有 \(x \le y\) 或 \(y \le x\)。去掉最后一条得到的是%
\term{偏序}{partial order}——集合的包含关系就是偏序而非全序，
因为两个集合可以互不包含。

\subsection*{实数列的收敛}

\begin{definition}[数列收敛]
  \label{def:seq-limit-R}
  设 \(\seq{a_{n}}\) 为实数列，\(a \in \R\)。称 \(\seq{a_{n}}\) \term{收敛}{converge}
  于 \(a\)，记作 \(a_{n} \to a\) 或 \(\lim_{n \to \infty} a_{n} = a\)，
  若对任意 \(\varepsilon > 0\) 存在 \(N\)，使 \(n \ge N\) 时 \(\abs{a_{n}-a} < \varepsilon\)。
\end{definition}

第 2 章将把这条定义原样推广到度量空间，届时只需把 \(\abs{a_{n}-a}\)
换成 \(d(a_{n},a)\)。下面这条命题本章会反复用到，就地证出。
其中 (i) 到第 2 章会以度量空间的形式重证（\cref{cor:limit-unique}），
(ii) 用到 \(\R\) 的域运算，一般度量空间中没有对应物。

\begin{proposition}[极限唯一与四则运算]
  \label{prop:limit-basics}
  设 \(a_{n} \to a\)，\(b_{n} \to b\)。则
  \begin{enumerate}[label=(\roman*)]
    \item 极限唯一：若同时 \(a_{n} \to a'\)，则 \(a = a'\)；
    \item \(a_{n} + b_{n} \to a + b\)，\(a_{n}b_{n} \to ab\)；
          若 \(b \neq 0\) 且各 \(b_{n} \neq 0\)，则 \(a_{n}/b_{n} \to a/b\)；
    \item 保序性：若 \(a_{n} \le b_{n}\) 对一切 \(n\) 成立，则 \(a \le b\)。
  \end{enumerate}
\end{proposition}

\begin{proof}
  (i) 设 \(a \neq a'\)，令 \(\varepsilon = \abs{a-a'}/2 > 0\)。
  取 \(N\) 使 \(n \ge N\) 时 \(\abs{a_{n}-a} < \varepsilon\) 且 \(\abs{a_{n}-a'} < \varepsilon\)，则
  \[
    \abs{a-a'} \le \abs{a-a_{N}} + \abs{a_{N}-a'} < 2\varepsilon = \abs{a-a'} ,
  \]
  矛盾。

  (ii) \emph{和}。给定 \(\varepsilon>0\)，取 \(N\) 使 \(n \ge N\) 时
  \(\abs{a_{n}-a}<\varepsilon/2\) 且 \(\abs{b_{n}-b}<\varepsilon/2\)，则
  \(\abs{(a_{n}+b_{n})-(a+b)} \le \abs{a_{n}-a}+\abs{b_{n}-b} < \varepsilon\)。

  \emph{积}。先说明收敛列有界：取 \(\varepsilon=1\) 得 \(N\) 使 \(n \ge N\) 时
  \(\abs{a_{n}} < \abs{a}+1\)，于是
  \(M := \max\set{\abs{a_{1}},\dots,\abs{a_{N-1}},\ \abs{a}+1}\) 是 \(\seq{a_{n}}\) 的界。由
  \[
    \abs{a_{n}b_{n}-ab} = \abs{a_{n}(b_{n}-b) + (a_{n}-a)b}
      \le M\abs{b_{n}-b} + \abs{b}\abs{a_{n}-a} ,
  \]
  给定 \(\varepsilon>0\)，让右端两项各小于 \(\varepsilon/2\) 即可。

  \emph{商}。先证 \(1/b_{n} \to 1/b\)。取 \(N_{1}\) 使 \(n \ge N_{1}\) 时
  \(\abs{b_{n}-b} < \abs{b}/2\)，于是 \(\abs{b_{n}} > \abs{b}/2\)。则对 \(n \ge N_{1}\)，
  \[
    \abs[\Big]{\frac{1}{b_{n}} - \frac{1}{b}}
      = \frac{\abs{b_{n}-b}}{\abs{b_{n}}\abs{b}}
      < \frac{2\abs{b_{n}-b}}{\abs{b}^{2}} \to 0 .
  \]
  再与积的情形合起来。

  (iii) 设 \(a > b\)，令 \(\varepsilon = (a-b)/2 > 0\)。取 \(N\) 使 \(n \ge N\) 时
  \(\abs{a_{n}-a}<\varepsilon\) 且 \(\abs{b_{n}-b}<\varepsilon\)，则
  \[
    b_{N} < b + \varepsilon = \frac{a+b}{2} = a - \varepsilon < a_{N} ,
  \]
  与 \(a_{N} \le b_{N}\) 矛盾。
\end{proof}

\begin{pitfall}
  (iii) 中的不等号不能改为严格：\(1/n > 0\) 对一切 \(n\) 成立，
  而极限 \(0\) 并不大于 \(0\)。取极限会把严格不等号\emph{磨平}成不严格的，
  这是初学时最常见的错误之一。
\end{pitfall}

\subsection*{量词及其否定}

「对一切」记作 \(\forall\)，「存在」记作 \(\exists\)。本章大量证明用反证法，
因而要能准确写出一个陈述的否定。规则只有两条，反复套用即可：
\begin{equation}
  \label{eq:quantifier-negation}
  \lnot\bigl(\forall x,\ P(x)\bigr) \iff \exists x,\ \lnot P(x),
  \qquad
  \lnot\bigl(\exists x,\ P(x)\bigr) \iff \forall x,\ \lnot P(x).
\end{equation}
即：否定穿过量词时，\(\forall\) 与 \(\exists\) 互换，否定落到最里面的命题上。

\begin{example}
  \label{ex:negate-convergence}
  写出「\(a_{n} \to a\)」的否定。
  \begin{worked}
    原陈述是 \(\forall \varepsilon>0,\ \exists N,\ \forall n \ge N,\
    \abs{a_{n}-a} < \varepsilon\)。逐层套用\cref{eq:quantifier-negation}：
    \[
      \exists \varepsilon>0,\ \forall N,\ \exists n \ge N,\
      \abs{a_{n}-a} \ge \varepsilon .
    \]
    读作：存在一个正数 \(\varepsilon\)，使得无论走到多远，
    后面总还有项与 \(a\) 相差不小于 \(\varepsilon\)。

    注意三个量词全部翻转，且最后的严格不等号变为不严格。
    这两处是最常出错的地方。
  \end{worked}
\end{example}

\section{有理数系的缺陷}
\label{sec:rational-gap}

\Cref{prop:sqrt2-irrational} 通常用来说明有理数系的不足，但它所提供的信息
相当有限，仅断言某个特定的数不属于 \(\Q\)。真正的缺陷更为根本，
并且可以不涉及平方根而陈述。

\begin{proposition}
  \label{prop:q-cut-fails}
  取
  \begin{equation}
    \label{eq:AB-cut}
    A = \setst{x \in \Q}{x > 0,\ x^{2} < 2}, \qquad
    B = \setst{x \in \Q}{x > 0,\ x^{2} > 2}.
  \end{equation}
  则 \(A, B\) 非空，且对一切 \(a \in A\)、\(b \in B\) 有 \(a < b\)；
  但不存在 \(c \in \Q\) 使得对一切 \(a \in A\)、\(b \in B\) 都有 \(a \le c \le b\)。
\end{proposition}

\begin{strategy}
  要证「不存在这样的 \(c\)」，标准办法是反设这样的 \(c\) 存在，再从它出发造出一个更靠近空隙的数，
  从而与 \(c\) 所处的位置矛盾。下面的 \(\xi\) 就是这样造出来的：
  当 \(c\) 偏小时 \(\xi\) 把它往右推，当 \(c\) 偏大时把它往左拉，
  唯有两个方向都推不动，\(c\) 才可能存在；而 \(\xi\) 总能推动它。
\end{strategy}

\begin{proof}
  \(1 \in A\)，\(2 \in B\)，故两者非空。若 \(a \in A\)、\(b \in B\)，则
  \(b - a = (b^{2} - a^{2})/(b + a) > 0\)，故 \(a < b\)。

  设有这样的 \(c \in \Q\)。由\cref{prop:sqrt2-irrational}，\(c^{2} \neq 2\)。令
  \begin{equation}
    \label{eq:xi-construction}
    \xi = \frac{2c + 2}{c + 2},
    \qquad\text{于是}\qquad
    \xi - c = -\frac{c^{2} - 2}{c + 2},
    \qquad
    \xi^{2} - 2 = \frac{2(c^{2} - 2)}{(c + 2)^{2}}.
  \end{equation}
  由 \(1 \in A\) 与 \(a \le c\) 得 \(c \ge 1\)，故 \(c + 2 > 0\)，
  从而 \(\xi \in \Q\) 且 \(\xi > 0\)。若 \(c^{2} < 2\)，由\cref{eq:xi-construction}
  得 \(\xi > c\) 且 \(\xi^{2} < 2\)，即 \(\xi \in A\) 却大于 \(c\)，与 \(c\) 是 \(A\)
  的上界矛盾。若 \(c^{2} > 2\)，同理得 \(\xi < c\) 且 \(\xi \in B\)，
  与 \(c\) 是 \(B\) 的下界矛盾。
\end{proof}

\begin{remark}
  比较上述两个命题。\Cref{prop:sqrt2-irrational} 断言 \(\Q\) 中缺少某个元素；
  \cref{prop:q-cut-fails} 断言 \(\Q\) 的某个分割不存在分点。后者才是完备性所要
  弥补的缺陷：其陈述不涉及任何具体的数，只涉及序结构，因而可以原样移植到
  任意全序集。\Cref{sec:order-complete}即沿此线索展开。
\end{remark}

\section{有序域}
\label{sec:ordered-field}

\Cref{prop:q-cut-fails} 指出了 \(\Q\) 的缺陷，但要说清楚「补上这个缺陷」，先得知道这缺陷附在什么结构之上。\(\Q\) 与 \(\R\) 并非处处不同：四则运算的规则、
不等式的运算、绝对值的性质，两者完全一致，差别只在一处。本节先把相同的那部分
固定下来，下一节起再处理那唯一的差别。

\begin{concept}{有序域}
  \cwhy{\(\Q\) 与 \(\R\) 的差别只在一条性质上。要把这条差别单独提出来，
    先得给两者相同的那部分结构一个名字。}
  \crel{域是加减乘除的抽象，全序是大小比较的抽象，有序域是两者相容的合成。
    去掉序即得域，去掉运算而保留序即得全序集，后者正是\cref{sec:order-complete}所讨论的对象。}
  \cwhere{代数与序理论的交界：凡是既要算又要比大小的地方都用得上。
    \(\Q\)、\(\R\) 以及\cref{ex:non-archimedean} 的 \(\R(t)\) 都是有序域。}
  \cdo{凡只用到四则运算与不等号的推理，一次证完即在 \(\Q\)、\(\R\)、
    \(\R(t)\) 上同时成立。绝对值的三角不等式即是一例。}
\end{concept}

\begin{definition}[有序域]
  \label{def:ordered-field}
  设 \(K\) 是域，其上另给定全序 \(\le\)。若下述两条相容性条件成立：
  \begin{enumerate}[label=(\roman*)]
    \item 对一切 \(x, y, z \in K\)，\(x \le y \implies x + z \le y + z\)；
    \item 对一切 \(x, y \in K\) 与 \(z \ge 0\)，\(x \le y \implies xz \le yz\)；
  \end{enumerate}
  则称 \((K, +, \cdot, \le)\) 为\term{有序域}{ordered field}。
\end{definition}

有理数域 \(\Q\) 与实数域 \(\R\) 都是有序域。有序域的元素可以谈正负、
谈大小、谈绝对值，几乎全部初等不等式都只用到\cref{def:ordered-field}。
例如「\(x \le y\) 且 \(z < 0\) 蕴含 \(xz \ge yz\)」这条中学熟知的规则，
就是把 (ii) 用于 \(-z \ge 0\) 再移项得到的，其证明在任何有序域中一字不差。

下述性质看似显然，但并非每个有序域都具备。

\begin{definition}[阿基米德性]
  \label{def:archimedean}
  有序域 \(K\) 称为\term{阿基米德的}{Archimedean}，若对任意 \(a, b \in K\)
  且 \(a > 0\)，存在 \(n \in \N\) 使得 \(b < na\)。
\end{definition}

\begin{intuition}
  阿基米德性的直观内容是：以任一固定的正量反复累加，总能超过预先给定的量。
  用一把一厘米的尺子去量任何长度，量足够多次总能超过它。
  \Cref{thm:complete-implies-arch} 将说明，完备性自动排除了反例。
\end{intuition}

\begin{example}[{一个非阿基米德的有序域\optread}]
  \label{ex:non-archimedean}
  设 \(\R(t)\) 为实系数有理函数域。对非零的 \(f \in \R(t)\)，
  把 \(f\) 写成两个多项式之商，规定 \(f > 0\) 当且仅当分子与分母的
  最高次项系数同号。验证它确实定义全序并与域运算相容之后，
  \(\R(t)\) 成为有序域。但对一切 \(n \in \N\) 都有 \(t > n\)：
  因为 \(t - n\) 的最高次项系数为 \(1 > 0\)。于是取 \(a = 1\)、\(b = t\)，
  \cref{def:archimedean} 的要求不成立。这里 \(t\) 扮演「无穷大」的角色，
  \(1/t\) 则是正的无穷小。
  \begin{worked}
    需验证的是：所定义的正元集合 \(P\) 对加法与乘法封闭，且
    \(K \setminus \set{0}\) 被 \(P\) 与 \(-P\) 剖分。乘法封闭性由
    最高次项系数相乘即得。加法封闭性：先把两个分式的分母规范为
    最高次项系数为正，则两个分子的最高次项系数均为正；通分后新分子
    的最高次项系数，在两项次数相同时为二者之和、次数不同时为次数
    较高者的系数，两种情形都为正。剖分性由「同号」的三分律直接得到。
  \end{worked}
\end{example}

\begin{remark}
  \Cref{ex:non-archimedean} 初读可以略过，只需记住结论：
  有序域中可以存在无法用有限次累加超越的元素，阿基米德性正是排除这种情形的条件。
  它在\cref{thm:complete-implies-arch} 中会作为完备性的推论重新出现。
\end{remark}

\section{确界：定义与计算}
\label{sec:sup-calc}

本节引入本章最重要的概念，并把它算熟。定义本身只有两行，
真正需要练习的是：给定集合，如何求出它的确界并加以证明。

\begin{concept}{上确界}
  \cwhy{\cref{eq:sqrt2-decimal} 的数列在 \(\Q\) 中无处可去。要断言它有极限，须先保证它所趋向的位置上确有一个数。
    上确界正是把这个位置指出来的工具。}
  \crel{不妨把上界看作能盖住整个集合的天花板：装得下集合的天花板有无穷多块，
    高度可以任意抬高；上确界是其中\emph{最低}的一块。天花板未必碰到集合，
    这正是上确界可以不属于集合的缘故。集合若有最大元，天花板恰好压在它上面。
    第 4 章的紧性是上确界在拓扑层面的接替者。}
  \cwhere{序理论。凡是能比大小的地方都可以问「有没有最小的上界」，
    答案为是的结构统称序完备的。}
  \cdo{由它可证单调有界必收敛、闭区间套定理、Bolzano--Weierstrass 定理，
    以及闭区间上连续函数取到最值。分析学中几乎全部存在性定理都溯源于此。}
\end{concept}

\begin{remark}[选读]
  「取最小的上界」这一想法远不止用于 \(\R\)。任一偏序集都可以问同样的问题，
  由此得到\term{完备格}{complete lattice}与\term{完备布尔代数}{complete Boolean algebra}
  等结构；而把一个偏序集补成完备格的标准做法（Dedekind--MacNeille 完备化），
  与\cref{sec:dedekind}从 \(\Q\) 造 \(\R\) 的手法是同一件事。
  初读时略过这一段不影响任何后续内容。
\end{remark}

\begin{definition}[上界与上确界]
  \label{def:supremum}
  设 \(S \subseteq \R\) 非空。若存在 \(M \in \R\) 使得对一切 \(x \in S\)
  都有 \(x \le M\)，则称 \(M\) 为 \(S\) 的\term{上界}{upper bound}，
  并称 \(S\) \emph{有上界}。若 \(S\) 的全体上界之中存在最小者 \(\beta\)，
  则称 \(\beta\) 为 \(S\) 的\term{上确界}{supremum}，记作 \(\beta = \sup S\)。

  对偶地，\(m\) 称为 \(S\) 的\term{下界}{lower bound}，若对一切 \(x \in S\)
  有 \(x \ge m\)；\(S\) 的全体下界中的最大者称为\term{下确界}{infimum}，
  记作 \(\inf S\)。
\end{definition}

注意上界一般不唯一：若 \(M\) 是上界，则任何大于 \(M\) 的数也是上界。
上确界则是这一族上界中最靠左的那一个，因而唯一。

\begin{proposition}[上确界的 \(\varepsilon\) 刻画]
  \label{prop:sup-epsilon}
  设 \(S \subseteq \R\) 非空，\(\beta \in \R\)。则 \(\beta = \sup S\)
  当且仅当下述两条同时成立：
  \begin{enumerate}[label=(\roman*)]
    \item \(\beta\) 是上界：对一切 \(x \in S\)，有 \(x \le \beta\)；
    \item 对任意 \(\varepsilon > 0\)，存在 \(x_{0} \in S\) 使
          \(x_{0} > \beta - \varepsilon\)。
  \end{enumerate}
\end{proposition}

\begin{proof}
  设 \(\beta = \sup S\)。(i) 由定义。对 (ii)：\(\beta - \varepsilon < \beta\)，
  而 \(\beta\) 是\emph{最小}的上界，故 \(\beta - \varepsilon\) 不是上界，
  即存在 \(x_{0} \in S\) 使 \(x_{0} > \beta - \varepsilon\)。

  反之设 (i)(ii) 成立。由 (i)，\(\beta\) 是上界。设 \(b\) 是任一上界且 \(b < \beta\)，
  取 \(\varepsilon = \beta - b > 0\)，由 (ii) 存在 \(x_{0} \in S\) 使
  \(x_{0} > \beta - \varepsilon = b\)，与 \(b\) 是上界矛盾。故一切上界 \(b\)
  都满足 \(b \ge \beta\)，即 \(\beta\) 是最小上界。
\end{proof}

\begin{intuition}
  条件 (ii) 的含义是：把 \(\beta\) 往左挪动任意一点点，就不再是上界了。
  它是实际证明中最常用的形式。「最小」原本要拿全体上界来比较，
  而条件 (ii) 只要求找出\emph{一个}元素，验证起来容易得多。
\end{intuition}

\begin{strategy}[求上确界的标准两步]
  给定 \(S\)，先\emph{猜}出答案 \(\beta\)（通常从 \(S\) 中元素的变化趋势看出），
  再按\cref{prop:sup-epsilon} 验证两条：
  第一步证 \(\beta\) 是上界，通常归结为一个不等式；
  第二步取定 \(\varepsilon > 0\)，具体地\emph{构造}出一个 \(x_{0} \in S\)
  使 \(x_{0} > \beta - \varepsilon\)。第二步是关键所在，也是证明中最易出错的一步。
\end{strategy}

\begin{example}[闭区间与开区间]
  \label{ex:sup-intervals}
  求 \(\sup[0,1]\)、\(\inf[0,1]\)、\(\sup(0,1)\)、\(\inf(0,1)\)。
  \begin{worked}
    四个答案分别是 \(1, 0, 1, 0\)。

    以 \(\sup(0,1) = 1\) 为例。第一步：对一切 \(x \in (0,1)\) 有 \(x < 1\)，
    故 \(1\) 是上界。第二步：任取 \(\varepsilon > 0\)。
    若 \(\varepsilon \ge 1\)，取 \(x_{0} = 1/2\) 即有 \(x_{0} > 1 - \varepsilon\)；
    若 \(\varepsilon < 1\)，取 \(x_{0} = 1 - \varepsilon/2\)，则
    \(0 < x_{0} < 1\) 故 \(x_{0} \in (0,1)\)，且 \(x_{0} > 1 - \varepsilon\)。
    两步都成立，故 \(\sup(0,1) = 1\)。

    注意 \(1 \notin (0,1)\)：上确界不属于集合。而 \(\sup[0,1] = 1 \in [0,1]\)，
    此时上确界同时是最大元。
  \end{worked}
\end{example}

\begin{example}[由数列给出的集合]
  \label{ex:sup-sequence}
  设 \(S = \setst{1 - 1/n}{n \in \N}\)。求 \(\sup S\) 与 \(\inf S\)。
  \begin{worked}
    \(S = \set{0, 1/2, 2/3, 3/4, \dots}\)，各项递增趋向 \(1\)。

    \(\sup S = 1\)：第一步，\(1 - 1/n < 1\) 对一切 \(n\) 成立。
    第二步，任取 \(\varepsilon > 0\)，要找 \(n\) 使 \(1 - 1/n > 1 - \varepsilon\)，
    即 \(1/n < \varepsilon\)，即 \(n > 1/\varepsilon\)。
    由\cref{thm:complete-implies-arch}(ii) 这样的 \(n\) 存在。

    \(\inf S = 0\)：取 \(n = 1\) 得 \(0 \in S\)，而 \(1 - 1/n \ge 0\) 恒成立，
    故 \(0\) 是下界且属于 \(S\)，因而是最小元，也就是下确界。

    本例中上确界不属于 \(S\)，下确界属于 \(S\)。两种情形都会出现。
  \end{worked}
\end{example}

\begin{example}[两端都取不到]
  \label{ex:sup-alternating}
  设 \(S = \setst{(-1)^{n}\left(1 - \dfrac{1}{n}\right)}{n \in \N}\)。求 \(\sup S\)、\(\inf S\)。
  \begin{worked}
    偶数项 \(1 - 1/n\) 递增趋于 \(1\)，奇数项 \(-(1-1/n)\) 递减趋于 \(-1\)。
    故 \(\sup S = 1\)，\(\inf S = -1\)，两者都不属于 \(S\)。

    验证 \(\sup S = 1\)：上界显然。任取 \(\varepsilon > 0\)，取偶数 \(n > 1/\varepsilon\)，
    则该项等于 \(1 - 1/n > 1 - \varepsilon\)。下确界同理。
  \end{worked}
\end{example}

\begin{example}[回到空隙]
  \label{ex:sup-sqrt2}
  设 \(S = \setst{x \in \R}{x > 0,\ x^{2} < 2}\)。说明 \(\sup S\) 在 \(\R\) 中存在，
  并说明相应的集合 \(A = \setst{x \in \Q}{x > 0,\ x^{2} < 2}\) 在 \(\Q\) 中没有上确界。
  \begin{worked}
    \(S\) 非空（\(1 \in S\)）且有上界（若 \(x \ge 2\) 则 \(x^{2} \ge 4 > 2\)，
    故 \(2\) 是上界）。由\cref{ax:completeness}，\(\sup S\) 在 \(\R\) 中存在。
    可以进一步证明 \((\sup S)^{2} = 2\)，即 \(\sup S = \sqrt{2}\)（见\cref{exr:sup-sqrt2-value}）。

    而 \cref{prop:q-cut-fails} 表明，在 \(\Q\) 内 \(A\) 的上界集合没有最小元：
    对任何有理上界 \(c\) 都能造出更小的有理上界。故 \(A\) 在 \(\Q\) 中无上确界。

    这正是 \(\R\) 与 \(\Q\) 的全部差别所在。
  \end{worked}
\end{example}

\begin{example}[有限集与无上界的集合]
  \label{ex:sup-finite}
  （a）设 \(S\) 为有限非空集，求 \(\sup S\)。（b）\(\sup \Z\) 是否存在？
  \begin{worked}
    （a）有限非空集必有最大元 \(\max S\)（对元素个数用归纳法），
    而最大元显然是最小的上界，故 \(\sup S = \max S\)。
    有限集的情形下上确界不提供新信息，它的价值全在无限集上。

    （b）不存在。由\cref{thm:complete-implies-arch}(ii)，对任何 \(M \in \R\)
    都存在 \(n \in \N\) 使 \(n > M\)，故 \(\Z\) 没有上界，
    从而谈不上「最小的上界」。此时有些书写 \(\sup \Z = +\infty\)，
    这只是一个约定记号，须事先声明；本讲义中 \(\sup S\) 一律指实数，
    只对有上界的非空集合使用。
  \end{worked}
\end{example}

\begin{pitfall}
  \begin{enumerate}[label=(\arabic*), leftmargin=1.6em]
    \item \textbf{误以为上确界必属于集合。} \((0,1)\) 的上确界是 \(1\)，
          而 \(1 \notin (0,1)\)。属于集合的那种情形有专门的名字，叫最大元。
    \item \textbf{把\cref{prop:sup-epsilon}(ii) 的量词写反。}
          正确的是「对\emph{任意} \(\varepsilon > 0\)，\emph{存在} \(x_{0} \in S\)」。
          写成「存在 \(\varepsilon\)，对一切 \(x_{0}\)」就成了另一个命题。
    \item \textbf{只验证上界就断言是上确界。} \(2\) 是 \((0,1)\) 的上界，
          但不是上确界。两步缺一不可。
    \item \textbf{对无上界的集合谈上确界。} \(\sup \Z\) 不是实数。
          使用 \(\sup S\) 之前必须先说明 \(S\) 非空且有上界。
  \end{enumerate}
\end{pitfall}

\section{确界原理及其推论}
\label{sec:sup-principle}

上一节练习了确界的计算，但每一次都默认了「上确界存在」。
这件事对 \(\Q\) 不成立（\cref{ex:sup-sqrt2}），因此它不是可以推导出来的定理，
而必须作为对 \(\R\) 的要求写下来。

\begin{assumption}[确界公理]
  \label{ax:completeness}
  \(\R\) 中任一非空有上界的子集必有上确界。
\end{assumption}

这是 \(\R\) 区别于 \(\Q\) 的\emph{唯一}实质性质：两者同为有序域，
差别仅在于前者满足\cref{ax:completeness}。本节说明由它可以推出什么。

\begin{theorem}[单调有界定理]
  \label{thm:monotone-convergence}
  设数列 \(\seq{a_{n}}\) 单调递增且有上界，则 \(\seq{a_{n}}\) 收敛，
  且 \(\lim_{n \to \infty} a_{n} = \sup_{n} a_{n}\)。
\end{theorem}

\begin{strategy}
  要证收敛，先得有一个候选的极限值。数列本身只给出一列数，
  唯一能从中造出「它趋向的位置」的工具就是上确界。造出来之后，
  再用\cref{prop:sup-epsilon}(ii) 把「靠近上确界」翻译成 \(\varepsilon\) 语言。
\end{strategy}

\begin{proof}
  记 \(S = \setst{a_{n}}{n \in \N}\)。由假设 \(S\) 非空且有上界，
  据\cref{ax:completeness}，\(\beta = \sup S\) 存在。

  任取 \(\varepsilon > 0\)。由\cref{prop:sup-epsilon}(ii)，存在 \(N\) 使
  \(a_{N} > \beta - \varepsilon\)。又 \(\seq{a_{n}}\) 单调递增，
  故当 \(n \ge N\) 时
  \begin{equation}
    \label{eq:monotone-squeeze}
    \beta - \varepsilon < a_{N} \le a_{n} \le \beta < \beta + \varepsilon,
  \end{equation}
  即 \(\abs{a_{n} - \beta} < \varepsilon\)。由 \(\varepsilon\) 的任意性，
  \(a_{n} \to \beta\)。
\end{proof}

\begin{remark}
  回看\cref{eq:sqrt2-decimal}。那个数列单调递增且以 \(2\) 为上界，
  在 \(\R\) 中由\cref{thm:monotone-convergence} 必定收敛；
  在 \(\Q\) 中却不收敛。差别的全部来源就是\cref{ax:completeness}。
\end{remark}

\begin{example}[自然常数的存在性]
  \label{ex:e-limit}
  证明数列 \(a_{n} = \left(1 + \dfrac{1}{n}\right)^{n}\) 收敛。
  \begin{worked}
    由二项式定理，
    \[
      a_{n} = \sum_{k=0}^{n} \binom{n}{k} \frac{1}{n^{k}}
            = \sum_{k=0}^{n} \frac{1}{k!}
              \prod_{j=1}^{k-1}\left(1 - \frac{j}{n}\right).
    \]
    把 \(n\) 换成 \(n+1\)，右端每一项中的因子 \(1 - j/n\) 均增大，
    且求和多出一项非负项，故 \(a_{n+1} > a_{n}\)，数列单调递增。

    又因 \(\prod_{j=1}^{k-1}(1 - j/n) \le 1\) 且 \(k! \ge 2^{k-1}\)，
    \[
      a_{n} \le \sum_{k=0}^{n} \frac{1}{k!}
            \le 1 + \sum_{k=1}^{n} \frac{1}{2^{k-1}} < 3,
    \]
    数列有上界。由\cref{thm:monotone-convergence} 即得收敛，该极限记作 \(\eu\)。

    注意这个证明没有算出 \(\eu\) 是多少，只断言它存在。
    这正是完备性的典型用法：\emph{先保证极限存在，再研究它的性质}。
  \end{worked}
\end{example}

\begin{theorem}[闭区间套定理]
  \label{thm:nested-intervals}
  设闭区间列 \(I_{n} = [\alpha_{n}, \beta_{n}]\) 满足
  \(I_{1} \supseteq I_{2} \supseteq \cdots\)，则 \(\bigcap_{n} I_{n} \neq \varnothing\)。
  若进一步有 \(\beta_{n} - \alpha_{n} \to 0\)，则该交集恰含一点。
\end{theorem}

\begin{proof}
  由区间套关系，\(\seq{\alpha_{n}}\) 单调递增，\(\seq{\beta_{n}}\) 单调递减，
  且对一切 \(m, n\) 有 \(\alpha_{m} \le \beta_{n}\)（取下标较大者比较即得）。
  于是 \(\seq{\alpha_{n}}\) 有上界 \(\beta_{1}\)，令 \(c = \sup_{n} \alpha_{n}\)。
  对每个 \(n\)，\(\beta_{n}\) 是 \(\seq{\alpha_{m}}\) 的上界，故 \(c \le \beta_{n}\)；
  又 \(\alpha_{n} \le c\)。因此 \(c \in I_{n}\) 对一切 \(n\) 成立。

  若 \(\beta_{n} - \alpha_{n} \to 0\)，设 \(c, c'\) 均属于交集，
  则 \(\abs{c - c'} \le \beta_{n} - \alpha_{n} \to 0\)，故 \(c = c'\)。
\end{proof}

\begin{pitfall}
  \begin{enumerate}[label=(\arabic*), leftmargin=1.6em]
    \item \textbf{把\cref{thm:nested-intervals} 用到开区间上。}
          \((0, 1/n)\) 是递减的开区间列，交集为空。
    \item \textbf{把它用到无界闭集上。} \([n, +\infty)\) 递减，交集也为空。
          「闭」与「有界」缺一不可，这一对条件将在第 4 章统一为紧性。
  \end{enumerate}
\end{pitfall}

\section{回头看：序完备性的三种面孔}
\label{sec:order-complete}

现在把\cref{sec:sup-calc}与\cref{sec:sup-principle}的证明重读一遍，
问一个问题：这些证明用到了 \(\R\) 的哪些结构？

\cref{thm:monotone-convergence} 与\cref{thm:nested-intervals} 的证明里出现了减法
（在 \(\varepsilon\) 的估计中），但\cref{def:supremum} 本身、
以及「上界的最小者」这一说法，从头到尾只用到了 \(\le\)。
这提示我们：确界的理论也许根本不需要加法与乘法。本节验证这一点，
顺带说明「没有空隙」还有另外两种同样自然的说法。

以下把讨论从 \(\R\) 移到任意全序集。这样安排的目的是分辨哪些结论与域运算无关，
以便日后在没有运算的场合直接引用；第 2 章的度量空间正是这样的场合。

\begin{theorem}[序完备性的三种等价刻画]
  \label{thm:order-complete-equiv}
  设 \(X\) 为全序集。下述三条等价：
  \begin{enumerate}[label=(\roman*)]
    \item \emph{上确界性质}：\(X\) 的任一非空有上界的子集有上确界；
    \item \emph{下确界性质}：\(X\) 的任一非空有下界的子集有下确界；
    \item \emph{戴德金分割性质}：若 \(A, B \subseteq X\) 非空，且对一切
          \(a \in A\)、\(b \in B\) 有 \(a \le b\)，则存在 \(c \in X\) 使得
          对一切 \(a \in A\)、\(b \in B\) 有 \(a \le c \le b\)。
  \end{enumerate}
  满足其中任一条的全序集称为\term{序完备的}{order complete}。
\end{theorem}

\begin{strategy}
  三条互相等价，按 \((\mathrm{i}) \Rightarrow (\mathrm{ii}) \Rightarrow
  (\mathrm{iii}) \Rightarrow (\mathrm{i})\) 绕一圈即可。
  每一步的手法相同：把手上没有的那个界，改写成另一个集合的界。
  比如要造下确界，就去看「全体下界」这个集合的上确界。
\end{strategy}

\begin{proof}
  \((\mathrm{i}) \Rightarrow (\mathrm{ii})\)。设 \(A\) 非空且有下界。
  令 \(B\) 为 \(A\) 的全体下界之集，则 \(B\) 非空，且 \(A\) 中任一元素都是 \(B\)
  的上界，故 \(B\) 有上界。由 (i)，\(m = \sup B\) 存在。由于 \(A\) 的每个元素
  都是 \(B\) 的上界而 \(m\) 是最小上界，故对一切 \(a \in A\) 有 \(m \le a\)，
  即 \(m \in B\)。于是 \(m = \max B\)，按定义 \(m = \inf A\)。

  \((\mathrm{ii}) \Rightarrow (\mathrm{iii})\)。设 \(A, B\) 如 (iii) 所述。
  \(A\) 中每个元素都是 \(B\) 的下界，故 \(B\) 有下界，由 (ii) 知
  \(c = \inf B\) 存在。\(c\) 作为最大下界不小于 \(A\) 的任一元素，
  故对一切 \(a \in A\) 有 \(a \le c\)；\(c\) 作为 \(B\) 的下界又满足
  \(c \le b\) 对一切 \(b \in B\) 成立。

  \((\mathrm{iii}) \Rightarrow (\mathrm{i})\)。设 \(A\) 非空且有上界，
  令 \(B\) 为 \(A\) 的全体上界之集。则 \(B\) 非空，
  且对一切 \(a \in A\) 与 \(b \in B\) 都有 \(a \le b\)。
  由 (iii) 知存在 \(c\)，使 \(a \le c \le b\) 对一切这样的 \(a\) 与 \(b\) 成立。
  前半个不等式说明 \(c \in B\)，后半个说明 \(c\) 是 \(B\) 的最小元，即 \(c = \sup A\)。
\end{proof}

\begin{remark}
  证明中没有出现过一次加法或乘法。因此这三条是纯粹的序性质，
  与 \(\R\) 的域结构无关。

  由此还得到一个体例上的结论：以其中哪一条作为公理是可以选择的。
  \textcite{garling2013} 取上确界性质，\textcite{zorich2015} 取分割性质，
  两种处理给出同一个实数系。若只陈述确界公理并以之为唯一起点，
  容易使读者误以为完备性必然以确界的形式出现。
  以\cref{prop:q-cut-fails} 的记号重述：\(\Q\) 不满足 (iii)，
  因而也不满足 (i) 与 (ii)。
\end{remark}

\section{实数系的定义与唯一性}
\label{sec:def-reals}

至此两块材料都已备齐：\cref{sec:ordered-field}给出 \(\Q\) 与 \(\R\) 共有的
代数与序结构，\cref{sec:order-complete}给出 \(\Q\) 所缺而 \(\R\) 所有的那一条。
把两者合起来就得到实数系的定义。

\begin{definition}[实数系]
  \label{def:reals}
  \term{实数系}{real number system} \(\R\) 是序完备的有序域。
\end{definition}

本定义综合了前几节的内容：域公理与序公理刻画 \(\Q\) 已具备的结构，
序完备性刻画 \(\Q\) 所缺失的结构。定义本身既未断言这样的对象存在，
也未断言它唯一。两者都成立，但其地位不同。

\begin{theorem}[{唯一性\optread}]
  \label{thm:uniqueness}
  设 \(\R\) 与 \(\R'\) 都是序完备的有序域，则存在唯一的双射
  \(j \mapsdef \R \to \R'\) 使得对一切 \(x, y \in \R\) 有
  \(j(x + y) = j(x) + j(y)\)、\(j(xy) = j(x)j(y)\)，且 \(x < y \implies j(x) < j(y)\)。
\end{theorem}

\begin{remark}
  证明的思路是：两个域各自含有一份 \(\Q\) 的拷贝，先在有理数上把 \(j\) 定死，
  再用二进制逼近 \(x_{n} = \floor{2^{n}x}/2^{n}\) 把 \(j\) 延拓到全体实数，
  最后验证运算与序均得保持。技术细节冗长而无新意，本讲义置于\cref{sec:uniqueness-proof}，
  完整叙述可参见\textcite{garling2013} 的 3.3 节。初读可跳过。
\end{remark}

\begin{remark}[一段史实]
  柯西于 1821 年出版《分析教程》，其中首次给出了数学分析的严格叙述，
  但他把实数的性质当作已知而未加追问。1858 年，戴德金在苏黎世高等工业学校
  准备微分学讲义时，按他自己的说法，比以往任何时候都更强烈地感到算术缺乏
  真正科学的基础，遂发现了用分割构造实数的方法；这一结果直到 1872 年才发表。
  从柯西到戴德金相隔半个世纪，可见把「数系没有空隙」说精确并非易事。
  \cref{def:reals} 把这半个世纪的结果压缩成了一行。
  史料见\textcite{garling2013} 3.1 节。
\end{remark}

存在性只能靠构造。历史上有两种途径：戴德金取 \(\Q\) 的分割，
康托尔取 \(\Q\) 中的 Cauchy 列。两者都放在\cref{app:construction}。
在此之前，我们照\textcite{amann2005} 的做法，把构造当作已知，
转而从\cref{def:reals} 推出分析学所需的全部性质。

\begin{intuition}
  将构造与公理化分开处理是有意为之。分析学中几乎不需要用到实数由何种方式构造，
  所需要的只是\cref{def:reals} 所列的几条性质。先确立性质、后讨论构造，
  可以避免在与后文无关的技术细节上分散注意力。
\end{intuition}

\section{阿基米德性与有理数的稠密性}
\label{sec:archimedean}

\Cref{ex:non-archimedean} 表明阿基米德性并非有序域所固有。以下说明它是完备性的推论。
本节的三条结论在前面的例题中已多次借用，现在补上证明。

\begin{theorem}
  \label{thm:complete-implies-arch}
  设 \(\R\) 如\cref{def:reals}。则
  \begin{enumerate}[label=(\roman*)]
    \item \(\inf \setst{1/n}{n \in \N} = 0\)；
    \item \(\R\) 是阿基米德的；
    \item 若 \(x < y\)，则存在 \(r \in \Q\) 使 \(x < r < y\)。
  \end{enumerate}
\end{theorem}

\begin{proof}
  (i) 记 \(J = \setst{1/n}{n \in \N}\)。\(0\) 是 \(J\) 的下界，
  由\cref{thm:order-complete-equiv} 的 (ii)，\(l = \inf J\) 存在且 \(l \ge 0\)。
  设 \(l > 0\)。则 \(2l > l\)，故 \(2l\) 不是 \(J\) 的下界，
  于是存在 \(n\) 使 \(1/n < 2l\)，从而 \(1/(2n) < l\)。但 \(1/(2n) \in J\)，
  与 \(l\) 是下界矛盾。故 \(l = 0\)。

  (ii) 设 \(a > 0\)、\(b \in \R\)。若 \(b \le 0\) 取 \(n = 1\) 即可。
  设 \(b > 0\)。由 (i)，\(a/b > 0\) 不是 \(J\) 的下界，
  故存在 \(n\) 使 \(1/n < a/b\)，即 \(b < na\)。

  (iii) 先设 \(0 \le x < y\)。由 (i) 存在 \(n \in \N\) 使 \(1/n < y - x\)。令
  \[
    A = \setst{k \in \Z}{k \ge 0,\ k \le nx} .
  \]
  由 (ii) 知 \(A\) 有限，又 \(0 \in A\) 故非空，
  于是 \(A\) 有最大元 \(a\)，满足 \(a \le nx < a + 1\)。
  取 \(r = (a+1)/n\)，则
  \begin{equation}
    \label{eq:density-estimate}
    x < r = \frac{a}{n} + \frac{1}{n} \le x + \frac{1}{n} < x + (y - x) = y .
  \end{equation}
  若 \(x < 0 < y\) 取 \(r = 0\)；若 \(x < y \le 0\)，对 \(-y < -x\) 用已证情形再取相反数。
\end{proof}

\begin{remark}
  \Cref{thm:complete-implies-arch} 的 (i) 说明 \(\R\) 中没有正的无穷小，
  (ii) 说明其中没有无穷大。对照\cref{ex:non-archimedean}，\(\R(t)\) 两者兼有，
  故它虽为有序域，却不可能序完备。这提供了一个无须直接验证确界的判别方法。
\end{remark}

\section{距离、Cauchy 列与另一种完备性}
\label{sec:cauchy}

至此本章所讨论的都是序的性质。以下引入一个在陈述上与序无关的概念。

\begin{concept}{距离}
  \cwhy{确界原理只在有序的地方可说。要把收敛的概念带到函数、向量、矩阵上，
    需要一个不依赖大小比较的替代品。}
  \crel{距离由绝对值给出，而绝对值来自序；但一旦写成\cref{prop:d-is-metric} 的
    三条性质，它就可以脱离序独立存在。第 2 章把这三条取作度量空间的公理。}
  \cwhere{分析学与拓扑学的接口。泛函分析、微分几何、概率论中的
    Wasserstein 距离、数值分析中的误差估计，都以它为底座。}
  \cdo{用同一套语言在 \(C[a,b]\) 上谈函数列收敛、在 \(\R^{n}\) 上谈向量列收敛。
    第 2 章的压缩映射原理由此得出，它随后给出微分方程解的存在唯一性与反函数定理。}
\end{concept}

\begin{definition}[绝对值与距离]
  \label{def:metric-on-R}
  对 \(x \in \R\) 令 \(\abs{x} = \max\set{x, -x}\)，称为 \(x\) 的\term{绝对值}{absolute value}。
  对 \(x, y \in \R\) 令
  \begin{equation}
    \label{eq:def-d}
    d(x, y) = \abs{x - y},
  \end{equation}
  称为 \(x\) 与 \(y\) 之间的\term{距离}{distance}。
\end{definition}

\begin{proposition}
  \label{prop:d-is-metric}
  对一切 \(x, y, z \in \R\)：
  \begin{enumerate}[label=(\roman*)]
    \item \(d(x,y) \ge 0\)，且 \(d(x,y) = 0\) 当且仅当 \(x = y\)；
    \item \(d(x,y) = d(y,x)\)；
    \item \(d(x,z) \le d(x,y) + d(y,z)\)。
  \end{enumerate}
\end{proposition}

\begin{proof}
  (i) 与 (ii) 由 \(\abs{\cdot}\) 的定义直接得到。(iii) 由三角不等式
  \(\abs{u + v} \le \abs{u} + \abs{v}\)，取 \(u = x - y\)、\(v = y - z\) 即得。
\end{proof}

\begin{remark}
  \Cref{prop:d-is-metric} 的三条性质将在第 2 章抽象为\term{度量}{metric}
  的公理：任给一个集合与其上满足这三条的二元函数，就得到一个度量空间。
  这三条性质中不出现序关系。下述概念同样如此。
\end{remark}

\begin{concept}{Cauchy 列}
  \cwhy{判断收敛通常要先知道极限是什么，而\cref{eq:sqrt2-decimal} 恰恰是
    不知道极限是什么的情形。Cauchy 条件把收敛判据改写成只涉及数列自身各项的形式。}
  \crel{在 \(\R\) 上它与确界原理相差一条阿基米德性（\cref{thm:completeness-split}）。
    但它的陈述只用到距离，因而可以推广，而确界原理不能。}
  \cwhere{完备性概念的通用形态。完备度量空间、Banach 空间、Hilbert 空间
    均以它为定义；一致空间中须把数列换成 Cauchy 滤子，但想法不变。}
  \cdo{判别级数与函数列的收敛；构造完备化。\(L^{p}\) 空间与实数系本身
    都是完备化的产物。}
\end{concept}

\begin{definition}[Cauchy 列]
  \label{def:cauchy}
  数列 \(\seq{a_{n}}\) 称为 \term{Cauchy 列}{Cauchy sequence}，若对任意
  \(\varepsilon > 0\) 存在 \(N\)，使得当 \(m, n \ge N\) 时 \(d(a_{m}, a_{n}) < \varepsilon\)。
  若 \(\R\) 中每个 Cauchy 列都收敛，则称 \(\R\) 是 \term{Cauchy 完备的}{Cauchy complete}。
\end{definition}

\begin{intuition}
  收敛的定义要求各项靠近\emph{极限}，Cauchy 条件只要求各项\emph{彼此}靠近。
  前者需要事先知道极限是谁，后者不需要。
  \cref{eq:sqrt2-decimal} 是 Cauchy 列，在 \(\R\) 中收敛，在 \(\Q\) 中不收敛，
  可见「是否 Cauchy」是数列自身的性质，「是否收敛」则取决于它所在的数系。
\end{intuition}

在陈述本章的核心定理之前，须先说明一件事。\cref{def:cauchy} 中的
\(\varepsilon\) 取自 \(\R\)，而下面要讨论的是任意有序域 \(K\)。
在 \(K\) 中，「\(\seq{a_{n}}\) 是 Cauchy 列」应理解为：对 \(K\) 的\emph{每个}
正元素 \(\varepsilon\)，存在 \(N\) 使 \(m,n \ge N\) 时 \(\abs{a_{m}-a_{n}} < \varepsilon\)；
这里的绝对值取值于 \(K\)，不是实数。两个框架的形式相同，取值范围不同——
非阿基米德域中的 \(\abs{x-y}\) 可以是无穷小，它并不构成第 2 章所要求的实值度量。

\begin{theorem}[完备性的分解]
  \label{thm:completeness-split}
  设 \(K\) 为有序域，其中的收敛与 Cauchy 条件按上段理解。
  则 \(K\) 序完备，当且仅当 \(K\) 既是阿基米德的、又是 Cauchy 完备的。
\end{theorem}

\begin{proof}[证明思路]
  必要性分两条。阿基米德性即\cref{thm:complete-implies-arch} 的 (ii)。

  Cauchy 完备性要三步。设 \(\seq{a_{n}}\) 是 Cauchy 列。
  \emph{其一}，它有界：取 \(\varepsilon=1\) 得 \(N\) 使 \(m,n \ge N\) 时
  \(\abs{a_{m}-a_{n}}<1\)，于是 \(n \ge N\) 时 \(\abs{a_{n}} < \abs{a_{N}}+1\)，
  再与前 \(N-1\) 项取最大即得界（\cref{exr:cauchy-bounded}）。
  \emph{其二}，由 Bolzano--Weierstrass 定理它有收敛子列 \(a_{n_{k}} \to l\)；
  该定理是确界原理的推论，见\cref{exr:bw}。
  \emph{其三}，Cauchy 列一旦有收敛子列便整体收敛：给定 \(\varepsilon>0\)，
  取 \(N\) 使 \(m,n \ge N\) 时 \(\abs{a_{m}-a_{n}}<\varepsilon/2\)，
  再取子列下标 \(n_{K} \ge N\) 使 \(\abs{a_{n_{K}}-l}<\varepsilon/2\)，
  则 \(n \ge N\) 时 \(\abs{a_{n}-l} \le \abs{a_{n}-a_{n_{K}}} + \abs{a_{n_{K}}-l} < \varepsilon\)。
  （后两步在第 2 章以\cref{prop:cauchy-basics} 的形式对一般度量空间重述。）

  充分性：设 \(K\) 阿基米德且 Cauchy 完备，\(S \subseteq K\) 非空有上界。
  任取 \(s \in S\)，令 \(a_{0} = s - 1\)，再取 \(S\) 的一个上界 \(b_{0}\)。
  于是 \(a_{0}\) 不是 \(S\) 的上界（因 \(a_{0} < s\)），而 \(b_{0}\) 是。
  反复二等分 \([a_{n}, b_{n}]\)：若中点是 \(S\) 的上界则取左半，否则取右半。
  这样始终保持不变量「\(a_{n}\) 不是上界而 \(b_{n}\) 是上界」，且两个数列满足
  \(b_{n} - a_{n} = (b_{0} - a_{0})/2^{n}\)。阿基米德性保证该量可以任意小
  （若无阿基米德性，\(2^{n}\) 未必超过给定的元素，此步不能成立），
  于是 \(\seq{a_{n}}\) 是 Cauchy 列，由假设收敛于某个 \(\beta\)，
  而 \(\beta\) 即 \(\sup S\)。
\end{proof}

\begin{remark}[本章的核心]
  \Cref{thm:completeness-split} 把一条性质拆成了两条，而这两条的性质截然不同：
  \begin{itemize}
    \item 阿基米德性（\cref{def:archimedean}）的陈述里出现了 \(<\)，是一条\emph{序}陈述；
    \item Cauchy 完备性（\cref{def:cauchy}）的陈述里只出现 \(d\)，是一条\emph{度量}陈述。
  \end{itemize}
  自第 2 章起所讨论的空间本身不带序：函数空间上逐点比较只给出偏序，
  两个函数往往不可比，而它们之间的距离总有意义。
  度量理论因此不以「空间上有序」为前提，可以原样推广的只有 Cauchy 完备性。
  这不是说偏序上谈不了确界——\cref{exr:cut-vs-sup} 恰恰说明本章的序完备性理论
  在任意偏序集上成立；要点在于度量本身不指定序。
  这解释了后续抽象理论中何以出现「完备度量空间」而非「具有确界的空间」。
  确界原理并未弃置，它在 \(\R\) 上仍是最便利的工具，但它是 \(\R\)
  所特有的性质，不具备普遍性。
\end{remark}

\section{实数集不可数}
\label{sec:uncountable}

\Cref{thm:complete-implies-arch}(iii) 说 \(\Q\) 在 \(\R\) 中稠密，
这容易让人以为两者差别不大。本节说明差别是根本性的。先把「可数」说清楚。

\begin{definition}[可数]
  \label{def:countable}
  集合 \(S\) 称为\term{可数的}{countable}，若存在从 \(\N\) 到 \(S\) 的满射，
  或者 \(S\) 为有限集。不可数即不满足此条件。
\end{definition}

\begin{example}[几个可数集]
  \label{ex:countable}
  \begin{enumerate}[label=(\alph*)]
    \item \(\Z\) 可数：按 \(0, 1, -1, 2, -2, \dots\) 排列即得一个枚举。
    \item \(\N \times \N\) 可数：按对角线枚举，先排 \(m+n = 2\) 的一对，
          再排 \(m+n = 3\) 的两对，如此下去，每条对角线上只有有限多对。
    \item \(\Q\) 可数：每个有理数写成既约分数 \(p/q\)，对应到 \(\Z \times \N\)
          中的一个元素，而后者由 (a)(b) 可数。
    \item 可数多个可数集之并可数：把第 \(i\) 个集合的第 \(j\) 个元素放在
          坐标 \((i,j)\) 处，再用 (b)。
  \end{enumerate}
\end{example}

\begin{theorem}[康托尔]
  \label{thm:uncountable}
  \(\R\) 不可数。
\end{theorem}

\begin{strategy}
  要证不存在满射 \(f \mapsdef \N \to [0,1]\)，就对\emph{任给}的 \(f\)
  造出一个漏掉的数。造法是逐步缩小范围：第 \(n\) 步把当前区间三等分，
  取一段避开 \(f(n)\)。区间套定理保证这些区间有公共点，
  而每一步都避开了这个公共点。
\end{strategy}

\begin{proof}
  只需证区间 \([0,1]\) 不可数。设 \(f \mapsdef \N \to [0,1]\) 为任一映射。
  把 \([0,1]\) 三等分为三个闭子区间；\(f(1)\) 至多落在其中两个之内
  （只有当它是分点时才落在两个内），故至少有一个闭子区间 \(I_{1}\) 不含 \(f(1)\)。
  把 \(I_{1}\) 三等分，同理取其中不含 \(f(2)\) 的闭子区间 \(I_{2}\)。
  如此下去得到闭区间套
  \begin{equation}
    \label{eq:nested-intervals}
    I_{1} \supseteq I_{2} \supseteq \cdots, \qquad
    \abs{I_{n}} = 3^{-n}, \qquad f(n) \notin I_{n}.
  \end{equation}
  由\cref{thm:nested-intervals}，存在 \(\alpha \in \bigcap_{n} I_{n}\)。
  于是对一切 \(n\)，\(\alpha \in I_{n}\) 而 \(f(n) \notin I_{n}\)，
  故 \(\alpha \neq f(n)\)。因此 \(f\) 不是满射。
\end{proof}

\begin{corollary}
  \label{cor:irrationals}
  无理数集 \(\R \setminus \Q\) 不可数。
\end{corollary}

\begin{proof}
  由\cref{ex:countable}(c)，\(\Q\) 可数。若 \(\R \setminus \Q\) 也可数，
  则由\cref{ex:countable}(d)，\(\R\) 作为两个可数集之并可数，
  与\cref{thm:uncountable} 矛盾。
\end{proof}

\begin{remark}
  \Cref{cor:irrationals} 与稠密性合在一起，给出一幅与直觉不符的图景：
  \(\Q\) 在 \(\R\) 中处处稠密，任何两个实数之间都夹着有理数，
  可它只占「可数多个」位置，绝大多数实数都是无理数。
  这个反差在第 7 章讨论 Riemann 可积性时会再次出现，
  届时「可数」将被更细的\term{零测集}{null set}概念取代。
\end{remark}

\section{本章结论在更一般框架下的地位}
\label{sec:outlook}

把本章出现的各条性质按其所依赖的结构整理如下。表中「可推广至」一栏指明
该性质在后续哪一类空间上仍然有意义。

\begin{table}[htbp]
  \centering
  \caption{实数系各条性质所依赖的结构。第三栏说的是这条性质在哪一类结构上%
    \emph{说得出口}，不是说它在那里必定成立——\(\Q\) 是全序集，
    其中单调有界数列未必收敛，用有理端点夹逼无理数还能造出交集为空的闭区间套。

\section*{习题}
\addcontentsline{toc}{section}{习题}

习题分三档：标「例行」者检验定义与计算，应当全做；标「结构」者要求指出证明
所依赖的结构，是本章的重点；标「延伸」者指向后续章节，初读可略。

\begin{exercise}[例行]
  \label{exr:inf-def}
  仿照\cref{prop:sup-epsilon}，写出 \(\alpha = \inf S\) 的 \(\varepsilon\) 形式刻画。
  \begin{solution}
    \(\alpha = \inf S\) 当且仅当：（i）对一切 \(x \in S\) 有 \(x \ge \alpha\)；
    （ii）对任意 \(\varepsilon > 0\)，存在 \(x_{0} \in S\) 使 \(x_{0} < \alpha + \varepsilon\)。
  \end{solution}
\end{exercise}

\begin{exercise}[例行]
  \label{exr:sup-compute-1}
  求下列集合的上确界与下确界，并指出哪些属于集合本身：
  (a) \([-1, 3)\)；\quad
  (b) \(\setst{1/n}{n \in \N}\)；\quad
  (c) \(\setst{n/(n+1)}{n \in \N}\)；\quad
  (d) \(\setst{x \in \R}{x^{2} < 5}\)。
  \begin{solution}
    (a) \(\sup = 3 \notin S\)，\(\inf = -1 \in S\)。

    (b) \(\sup = 1 \in S\)（取 \(n=1\)），\(\inf = 0 \notin S\)。
    下确界的验证：\(0\) 是下界；任取 \(\varepsilon>0\)，
    由\cref{thm:complete-implies-arch}(ii) 存在 \(n > 1/\varepsilon\)，
    则 \(1/n < \varepsilon\)。

    (c) \(n/(n+1) = 1 - 1/(n+1)\) 递增趋于 \(1\)。
    \(\sup = 1 \notin S\)，\(\inf = 1/2 \in S\)（取 \(n=1\)）。

    (d) \(S = (-\sqrt{5}, \sqrt{5})\)，故 \(\sup = \sqrt{5}\)，\(\inf = -\sqrt{5}\)，
    均不属于 \(S\)。
  \end{solution}
\end{exercise}

\begin{exercise}[例行]
  \label{exr:sup-compute-2}
  设 \(S = \setst{m/n}{m, n \in \N,\ m < n}\)。求 \(\sup S\) 与 \(\inf S\)。
  \begin{solution}
    \(\sup S = 1\)：由 \(m < n\) 得 \(m/n < 1\)，故 \(1\) 是上界。
    任取 \(\varepsilon > 0\)，取 \(n > \max\set{1/\varepsilon,\,2}\) 与 \(m = n - 1\)（故 \(m \ge 1\)），
    则 \(m/n = 1 - 1/n > 1 - \varepsilon\)。故 \(\sup S = 1 \notin S\)。

    \(\inf S = 0\)：\(m/n > 0\) 故 \(0\) 是下界。取 \(m = 1\)、\(n\) 充分大，
    得 \(1/n < \varepsilon\)。故 \(\inf S = 0 \notin S\)。
  \end{solution}
\end{exercise}

\begin{exercise}[例行]
  \label{exr:max-sup}
  证明：\(S\) 有最大元当且仅当 \(\sup S\) 存在且 \(\sup S \in S\)。
  此时 \(\max S = \sup S\)。
  \begin{solution}
    设 \(M = \max S\)。则 \(M\) 是上界；又任一上界 \(b\) 满足 \(b \ge M\)
    （因 \(M \in S\)），故 \(M\) 是最小上界，即 \(M = \sup S \in S\)。

    反之设 \(\beta = \sup S \in S\)。\(\beta\) 是上界故 \(x \le \beta\)
    对一切 \(x \in S\) 成立，加上 \(\beta \in S\)，即 \(\beta = \max S\)。
  \end{solution}
\end{exercise}

\begin{exercise}[例行]
  \label{exr:sup-sum}
  设 \(A, B \subseteq \R\) 非空且均有上界，令
  \(A + B = \setst{a + b}{a \in A,\ b \in B}\)。证明 \(\sup(A + B) = \sup A + \sup B\)。
  \begin{solution}
    记 \(\alpha = \sup A\)，\(\beta = \sup B\)。任取 \(a \in A\)、\(b \in B\)，
    有 \(a + b \le \alpha + \beta\)，故 \(\sup(A+B) \le \alpha + \beta\)。

    反向：任取 \(\varepsilon > 0\)，存在 \(a_{0} \in A\) 使
    \(a_{0} > \alpha - \varepsilon/2\)，存在 \(b_{0} \in B\) 使
    \(b_{0} > \beta - \varepsilon/2\)，于是
    \(a_{0} + b_{0} > \alpha + \beta - \varepsilon\)。
    由 \(\varepsilon\) 任意性得 \(\sup(A+B) \ge \alpha + \beta\)。
  \end{solution}
\end{exercise}

\begin{exercise}[例行]
  \label{exr:sup-scalar}
  设 \(S \subseteq \R\) 非空，\(c > 0\)，记
  \(cS = \setst{cx}{x \in S}\)，\(-S = \setst{-x}{x \in S}\)。
  （a）设 \(S\) 有上界，求 \(\sup(cS)\)。
  （b）\(\sup(-S)\) 在什么条件下存在？此时它等于什么？
  \begin{solution}
    \(\sup(cS) = c\sup S\)：\(c\sup S\) 显然是上界；若 \(M\) 是 \(cS\) 的上界，
    则 \(M/c\) 是 \(S\) 的上界，故 \(M/c \ge \sup S\)，即 \(M \ge c\sup S\)。

    （b）\(\sup(-S)\) 存在当且仅当 \(-S\) 有上界，即当且仅当 \(S\) 有\emph{下界}。
    此时 \(\sup(-S) = -\inf S\)：\(x \ge m\) 对一切 \(x \in S\) 成立当且仅当
    \(-x \le -m\) 对一切 \(x \in S\) 成立，即 \(S\) 的下界与 \(-S\) 的上界
    一一对应且反序，取最大者对应取最小者。

    仅设 \(S\) 有上界并不够。取 \(S = \setst{x \in \R}{x \le 0}\)，
    它有上界 \(0\)，而 \(-S = \setst{x}{x \ge 0}\) 无上界，
    \(\sup(-S)\) 不是实数，\(\inf S\) 也不存在。

    本题用到了\cref{def:ordered-field} 的相容性条件，纯全序集上无此结论。
  \end{solution}
\end{exercise}

\begin{exercise}[例行]
  \label{exr:sup-monotone-set}
  设 \(\varnothing \neq A \subseteq B\) 且 \(B\) 有上界。证明 \(\sup A \le \sup B\)。
  再举例说明等号可以成立而 \(A \neq B\)。
  \begin{solution}
    \(\sup B\) 是 \(B\) 的上界，因而也是 \(A\) 的上界；\(\sup A\) 是 \(A\)
    的最小上界，故 \(\sup A \le \sup B\)。

    例：\(A = (0,1)\)，\(B = [0,1]\)，两者上确界均为 \(1\)。
  \end{solution}
\end{exercise}

\begin{exercise}[例行]
  \label{exr:sup-union}
  设 \(A, B\) 非空且均有上界。证明 \(\sup(A \cup B) = \max\set{\sup A,\ \sup B}\)。
  \begin{solution}
    记 \(M = \max\set{\sup A, \sup B}\)。\(M\) 是 \(A\) 与 \(B\) 的公共上界，
    故是 \(A \cup B\) 的上界。反之由\cref{exr:sup-monotone-set}，
    \(\sup A \le \sup(A\cup B)\) 且 \(\sup B \le \sup(A \cup B)\)，
    故 \(M \le \sup(A \cup B)\)。两式合并即得。
  \end{solution}
\end{exercise}

\begin{exercise}[例行]
  \label{exr:sup-sqrt2-value}
  设 \(S = \setst{x \in \R}{x > 0,\ x^{2} < 2}\)，\(\beta = \sup S\)（由\cref{ex:sup-sqrt2} 存在）。
  证明 \(\beta^{2} = 2\)。
  \begin{solution}
    用\cref{prop:q-cut-fails} 中的构造。令 \(\xi = (2\beta+2)/(\beta+2)\)，
    则\cref{eq:xi-construction} 的两个恒等式对实数同样成立。

    若 \(\beta^{2} < 2\)，则 \(\xi > \beta\) 且 \(\xi^{2} < 2\)，
    即 \(\xi \in S\) 却大于上界 \(\beta\)，矛盾。
    若 \(\beta^{2} > 2\)，则 \(\xi < \beta\) 且 \(\xi^{2} > 2\)；
    此时对一切 \(x \in S\) 有 \(x^{2} < 2 < \xi^{2}\)，故 \(x < \xi\)，
    即 \(\xi\) 是比 \(\beta\) 更小的上界，与 \(\beta\) 是最小上界矛盾。
    故 \(\beta^{2} = 2\)。
  \end{solution}
\end{exercise}

\begin{exercise}[例行]
  \label{exr:monotone-apply}
  设 \(x_{1} = 1\)，\(x_{n+1} = \dfrac{1}{2}\left(x_{n} + \dfrac{2}{x_{n}}\right)\)。
  证明 \(\seq{x_{n}}\) 收敛，并求其极限。
  \begin{solution}
    先证 \(x_{n} > 0\)（归纳显然）与 \(x_{n}^{2} \ge 2\)（\(n \ge 2\)）：
    由均值不等式 \(x_{n+1} = \frac{1}{2}(x_{n} + 2/x_{n}) \ge \sqrt{2}\)。

    再证递减（\(n \ge 2\)）：\(x_{n} - x_{n+1} = \frac{1}{2}(x_{n} - 2/x_{n})
    = \frac{x_{n}^{2}-2}{2x_{n}} \ge 0\)。

    于是 \(\seq{x_{n}}_{n \ge 2}\) 单调递减且有下界 \(\sqrt{2}\)，
    由\cref{thm:monotone-convergence} 的对偶形式收敛，设极限为 \(L \ge \sqrt2\)。
    对递推式取极限得 \(L = \frac{1}{2}(L + 2/L)\)，解出 \(L^{2} = 2\)，
    故 \(L = \sqrt{2}\)。这正是\cref{eq:sqrt2-decimal} 的一个更快的版本。
  \end{solution}
\end{exercise}

\begin{exercise}[例行]
  \label{exr:countable-examples}
  证明：(a) 两个可数集之积可数；(b) 可数集的任一子集可数；
  (c) 全体有限长的 \(0\)--\(1\) 串构成可数集。
  \begin{solution}
    (a) 由\cref{ex:countable}(b)，\(\N \times \N\) 可数；一般情形取满射
    \(\N \to A\)、\(\N \to B\) 复合即得。

    (b) 设 \(S\) 可数、\(T \subseteq S\) 非空。取 \(f \mapsdef \N \to S\) 满射，
    固定 \(t_{0} \in T\)，令 \(g(n) = f(n)\) 若 \(f(n) \in T\)，否则 \(g(n) = t_{0}\)。
    则 \(g \mapsdef \N \to T\) 是满射。

    (c) 长度为 \(k\) 的串共 \(2^{k}\) 个，是有限集；全体串是可数多个有限集之并，
    由\cref{ex:countable}(d) 可数。
  \end{solution}
\end{exercise}

\begin{exercise}[结构]
  \label{exr:cut-vs-sup}
  检查\cref{thm:order-complete-equiv} 的证明是否用到了「任意两元素可比较」
  这一条。若没有用到，说明该定理在任意\emph{偏序集}上是否仍然成立。
  \begin{solution}
    三步都只用到序关系的自反、反对称、传递，以及上界与下界的定义，
    \emph{全序的可比较性一次也没有用到}。因此\cref{thm:order-complete-equiv}
    在任意偏序集上原样成立，证明一字不改。

    容易误判的一处是「\(A\) 的每个元素都是 \(B\) 的上界」这类断言。
    它并非来自可比较性，而是来自 \(B\) 的\emph{定义}——我们把 \(B\) 取作 \(A\) 的
    全体下界之集，故按定义就有 \(b \le a\) 对一切 \(a \in A\)、\(b \in B\) 成立。
    在 (ii)\(\Rightarrow\)(iii) 一步中，这一关系则由题设直接给出。

    这个结果说明本章的完备性理论并不需要全序：它是纯粹的序理论结论。
    全序在别处才真正用到，例如\cref{thm:complete-implies-arch} 的三分律。
  \end{solution}
\end{exercise}

\begin{exercise}[结构]
  \label{exr:which-axiom}
  设 \(K\) 为阿基米德有序域，且其中每个单调递增有上界的数列都收敛。
  证明 \(K\) 满足确界原理。
  （这说明单调有界定理也可以充当完备性公理。）
  \begin{solution}
    设 \(S\) 非空有上界。仿\cref{thm:completeness-split} 的二分法：
    取 \(a_{0}\) 不是上界、\(b_{0}\) 是上界，反复二等分，
    保持不变量「\(a_{n}\) 不是上界而 \(b_{n}\) 是上界」。
    则 \(\seq{a_{n}}\) 单调递增且以 \(b_{0}\) 为上界，由假设收敛于某 \(\beta\)；
    \(\seq{b_{n}}\) 单调递减且收敛于同一 \(\beta\)（因 \(b_{n}-a_{n} \to 0\)，
    此处用到阿基米德性）。

    \(\beta\) 是上界：若某 \(x \in S\) 满足 \(x > \beta\)，则由 \(b_{n} \to \beta\)
    有某 \(b_{n} < x\)，与 \(b_{n}\) 是上界矛盾。
    \(\beta\) 最小：任一上界 \(c\) 满足 \(c \ge a_{n}\)（否则 \(a_{n}\) 是上界），
    取极限得 \(c \ge \beta\)。
  \end{solution}
\end{exercise}

\begin{exercise}[结构]
  \label{exr:q-not-complete}
  不借助\cref{prop:q-cut-fails}，直接证明 \(\Q\) 不满足确界原理。即证集合
  \[
    A = \setst{x \in \Q}{x > 0,\ x^{2} < 2}
  \]
  在 \(\Q\) 中没有上确界。
  \begin{solution}
    设 \(\beta \in \Q\) 为 \(A\) 在 \(\Q\) 中的上确界。由\cref{prop:sqrt2-irrational}
    有 \(\beta^{2} \neq 2\)。取 \(\xi = (2\beta+2)/(\beta+2) \in \Q\)。
    若 \(\beta^{2} < 2\)，则 \(\xi \in A\) 且 \(\xi > \beta\)，与 \(\beta\) 是上界矛盾；
    若 \(\beta^{2} > 2\)，则 \(\xi < \beta\) 且 \(\xi\) 仍是 \(A\) 的上界
    （因 \(x \in A \Rightarrow x^{2} < 2 < \xi^{2} \Rightarrow x < \xi\)），
    与最小性矛盾。
  \end{solution}
\end{exercise}

\begin{exercise}[结构]
  \label{exr:archimedean-fails}
  在\cref{ex:non-archimedean} 的有序域 \(\R(t)\) 中，考察元素 \(1/t\)。
  证明 \(0 < 1/t < 1/n\) 对一切 \(n \in \N\) 成立，并由此说明数列
  \(\seq{1/n}\) 在 \(\R(t)\) 中不以 \(0\) 为极限。这与%
  \cref{thm:complete-implies-arch}(i) 有何关系？
  \begin{solution}
    \(1/t > 0\) 因分子分母最高次系数同为正。\(1/n - 1/t = (t - n)/(nt)\)，
    分子最高次系数为 \(1\)，分母为 \(n > 0\)，故该差为正，即 \(1/t < 1/n\)。

    于是取 \(\varepsilon = 1/t > 0\)，对一切 \(n\) 都有 \(1/n > \varepsilon\)，
    故 \(\seq{1/n}\) 不收敛于 \(0\)。这说明%
    \cref{thm:complete-implies-arch}(i) 的结论依赖完备性：
    在非阿基米德的有序域中它不成立。
  \end{solution}
\end{exercise}

\begin{exercise}[结构]
  \label{exr:bw}
  证明 Bolzano--Weierstrass 定理：\(\R\) 中每个有界数列都有收敛子列。
  指出证明中确界原理用在何处。
  \begin{solution}
    设 \(\seq{a_{n}}\) 有界，取 \([\alpha_{0}, \beta_{0}]\) 含全部项。
    反复二等分：两半之中至少有一半含 \(\seq{a_{n}}\) 的无穷多项，取之为
    \([\alpha_{1}, \beta_{1}]\)，如此得闭区间套，长度为 \(2^{-k}(\beta_{0}-\alpha_{0})\)。
    在第 \(k\) 个区间中取一项 \(a_{n_{k}}\) 且 \(n_{k} > n_{k-1}\)，得子列。

    确界原理用在两处：一是\cref{thm:nested-intervals} 断言区间套有公共点
    \(\alpha\)，其证明用了上确界；二是断言区间长度趋于零，
    这依赖\cref{thm:complete-implies-arch}(i)，而后者也由确界原理推出。
    子列收敛于 \(\alpha\)。
  \end{solution}
\end{exercise}

\begin{exercise}[结构]
  \label{exr:cauchy-bounded}
  证明 Cauchy 列必有界。这个证明用到了序吗？
  \begin{solution}
    取 \(\varepsilon = 1\)，存在 \(N\) 使 \(m, n \ge N\) 时 \(d(a_{m}, a_{n}) < 1\)。
    于是对 \(n \ge N\) 有 \(d(a_{n}, a_{N}) < 1\)，全部项落在有限个数
    \(d(a_{1},a_{N}), \dots, d(a_{N-1},a_{N}), 1\) 的最大值所界定的范围内。

    证明只用到 \(d\) 的三条性质与有限集有最大元。注意所比较的是
    \(d\) 的取值（它们本来就是实数），\emph{数列所在的空间上并未用到任何序}。
    因此这个结论在任意度量空间中都成立（其中「有界」指含于某个球内），
    第 2 章将原样重述它。
  \end{solution}
\end{exercise}

\begin{exercise}[结构]
  \label{exr:nested-fail}
  \Cref{thm:nested-intervals} 中，若把闭区间换成开区间，或换成无界闭集，
  结论如何失效？各给一个反例，并指出证明中哪一步断了。
  \begin{solution}
    换成开区间：\((0, 1/n)\) 递减，交集为空。断在最后一步：
    \(c = \sup \alpha_{n} = 0\) 存在，但 \(0 \notin (0,1/n)\)，
    因为开区间不含其端点。

    换成无界闭集：\([n, +\infty)\) 递减，交集为空。断在第一步：
    \(\seq{\alpha_{n}} = \seq{n}\) 没有上界，上确界不存在。

    两个反例说明「闭」与「有界」缺一不可，这一对条件将在第 4 章统一为紧性。
  \end{solution}
\end{exercise}

\begin{exercise}[延伸]
  \label{exr:sup-not-metric}
  \needlater\
  举出一个集合与其上的度量，使得该集合上无法定义与度量相容的全序。
  由此说明为什么第 2 章起不再以确界为主要工具。
  （第 5 章会补上本题所缺的一步并回引。）
  \begin{solution}
    取平面 \(\R^{2}\) 及欧氏距离。设有全序 \(\preceq\) 与之相容
    （意即序区间构成的族生成同一拓扑）。去掉一点后 \(\R^{2}\) 仍连通，
    而全序集去掉一个非端点必分成两个非空的开集之并，矛盾；
    由于全序至多有两个端点，这样的点总能取到。

    注意结论并非「\(\R^{2}\) 上没有全序」。由良序定理它有全序，
    此处断言的是\emph{没有与度量相容的全序}。距离则始终存在。
    这正是\cref{sec:cauchy}末尾所说的情形。
  \end{solution}
\end{exercise}

\begin{exercise}[延伸]
  \label{exr:cauchy-vs-sup}
  写出「\(S\) 有上确界」与「\(\seq{a_{n}}\) 是 Cauchy 列」两个陈述的形式表达，
  逐一指出其中出现的每个符号属于哪一类结构（序、距离、域运算）。
  由此解释为何前者不能推广到一般度量空间。
  \begin{solution}
    前者：\(\exists \beta\,[\forall x \in S\,(x \le \beta) \wedge
    \forall b\,(\forall x \in S\,(x \le b) \to \beta \le b)]\)，
    只出现 \(\le\)，属序结构。

    后者：\(\forall \varepsilon > 0\,\exists N\,\forall m,n \ge N\,
    (d(a_{m},a_{n}) < \varepsilon)\)，出现 \(d\) 与 \(\varepsilon\) 上的 \(<\)。
    后一个 \(<\) 比较的是实数（距离的取值），不是空间中的元素。

    一般度量空间的元素之间没有 \(\le\)，故前者的陈述根本写不出来；
    后者只需要 \(d\)，因而可原样移植。这正是\cref{sec:cauchy}末尾「本章的核心」一节所论。
  \end{solution}
\end{exercise}

\begin{exercise}[延伸]
  \label{exr:sup-lattice}
  称偏序集 \(P\) 为\emph{完备格}，若其\emph{任一}子集（包括空集）
  都有上确界。证明：完备格必有最大元与最小元。
  这与\cref{thm:order-complete-equiv} 的 (i) 有何差别？
  \begin{solution}
    取 \(S = P\)，得 \(\sup P\) 存在，它是最大元。
    取 \(S = \varnothing\)：任何元素都是空集的上界，故 \(\sup \varnothing\)
    是全体元素的最小者，即最小元。

    差别有二：\cref{thm:order-complete-equiv}(i) 只要求\emph{非空且有上界}的
    子集有上确界，且设在全序集上。\(\R\) 不是完备格——它没有最大元，
    \(\R\) 的子集 \(\Z\) 就没有上确界。
  \end{solution}
\end{exercise}

\begin{exercise}[延伸]
  \label{exr:construction}
  阅读\cref{sec:dedekind}的戴德金分割构造，说明为什么按该构造得到的 \(\R\)
  自动满足\cref{thm:order-complete-equiv} 的 (iii)，而验证域公理反倒麻烦。
  \begin{solution}
    分割性质是构造方式本身的直接推论：一个分割就是一个实数，
    分点按定义即属于新构造的集合。而域公理需要逐条验证分割的
    加法与乘法定义良好，尤其是乘法要按符号分情形讨论，
    以及乘法逆元的存在性。这正是构造法的代价：完备性变得平凡，
    代数结构变得琐碎。康托尔的 Cauchy 列构造恰好相反，
    域公理几乎自动成立，完备性则需要对角线论证。
  \end{solution}
\end{exercise}
