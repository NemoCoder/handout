lim_{x→∞} ∫₀^∞ K(x/√u)φ(u) du = 0

(d) ∫₀^∞ K(x)x^(-it) dx = Γ(1 + it) ≠ 0 if t is real.
(e) Put H(x) = 1/(εx) if (1 + ε)^(-1) < x < 1, H(x) = 0 otherwise. Conclude that
lim_{x→∞} (1/εx) ∫_x^(1+ε)x^(-1)φ(y) dy = 0.
(f) By (b) and (e), lim_{x→∞} φ(x) = 0.
