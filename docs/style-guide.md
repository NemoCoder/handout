# 写作与排版规范

本讲义拟公开发布，语言与体例按正式出版物的标准执行。本文件是动笔前的必读件，
也是评审与自查的依据。规范取自《出版物上数字用法》（GB/T 15835—2011）、
《标点符号用法》（GB/T 15834—2011）、《量和单位》（GB 3100~3102）与
《信息与文献 参考文献著录规则》（GB/T 7714—2015），并结合国内教材的通行做法。

---

## 一、语体

讲义是书面语体，不是课堂口语的转写，也不是网络文章。

**用规范书面语。** 不用口语词与网络用语（「搞清楚」「这块儿」「妥妥的」「干货」），
不用语气词收尾（「呢」「啦」「嘛」），不用感叹号作强调。

**称谓要克制。** 推导过程中可用「我们」引导（「我们先考察最简单的情形」），
但不宜句句都用。避免直接对读者说教（「你一定要记住」「大家想一想」），
把祈使句改写为陈述句或设问句。

**一句话说一件事。** 长句拆开。定语层层套叠会让中文读起来像译文，
凡出现三层以上「的」，都应改写。

**杜绝 AI 腔与套话。** 下列写法在本讲义中一律不用：

- 空洞的拔高与象征化收尾——「这不仅仅是一个公式，更是一种思维方式」
  「深刻地体现了……的智慧」。
- 宣传性形容词堆叠——「极其重要的」「至关重要的」「令人瞩目的」。
- 以「-ing」式动词开头的伪分析——「值得注意的是」「需要指出的是」
  连续出现三次以上。
- 无出处的归因——「众所周知」「研究表明」「有学者认为」而不给文献。
- 三段排比成瘾——凡事都凑成三点，且每点长度雷同。
- 「不是……而是……」句式反复使用。
- 破折号滥用。中文正式文本中破折号出现频率应远低于英文。

**下判断要给理由。** 「这个假设是合理的」须说明为什么合理；
「这一结论很重要」须说明它在后文何处被用到。凡是无法给出理由的评价，删去。

## 二、术语

**首次出现须给英文。** 用 `\term{中文}{English}`，宏会自动处理首次与后续的差别，
并生成书末的「术语中英对照」表。不要手写「稀缺性（scarcity）」。

**全书统一。** 同一概念只用一个中文译名。`supremum` 统一译「上确界」，
不与「最小上界」混用；确需说明两者是同一事物时，在首次出现处用一句话交代，
其后固定用一个。

**译名以国内通行教材为准。** 存在多个通行译名时，选用面最广的一个，
并在术语表中把另一个作为「亦译」记入。

**中文译名有歧义时，正文直接用英文原名，不生造译名。** 用 `\termen{English}{中文注}`，
首次排作「separation（隔离）」，其后仅排英文；索引条目与 `\term` 同格式，
两类术语在书末对照表里体例一致。适用的两种情形：

1. **本书内部重名。** 同一个中文词已经被另一个概念占用，再借用会读乱。
   例：`splitting`／`separation` 若译「分割」，与戴德金分割（`\term{分割}{cut}`）
   和 Riemann 积分的区间划分三处同名；若译「分离」，又与卷四的分离公理相撞。
   直接写 `\termen{separation}{隔离}`。
2. **该词是重要结论的名字，而通行中译不唯一。** 定理名、判别法名、
   以人名命名的对象，读者日后查文献、读英文教材时用的是英文，中译反而是障碍。

判断顺序是：先查通行教材有无定名，有则用中文；无定名或有上述冲突，才用英文原名。
**不要因为「英文看起来专业」而用英文**——中文有定名的一律用中文（`compact` 用「紧」，
不写 compact）。用了英文原名的，要在首次出现处一句话说明为什么（如「本书已把
『分割』给了戴德金分割」），不要让读者以为是漏译。

**英文原词的大小写。** 术语英文一律小写，除非是人名或专有名词
（`Nash equilibrium`、`Lagrange multiplier`）。

## 三、标点与字符

- 中文正文用全角标点。句号用「。」，不用「．」。
- 括号：中文语境用全角圆括号，括注英文或数字时可用半角圆括号并前后留空。
  本讲义的 `\term` 宏已统一处理术语括注，不必手动干预。
- 引号用直角引号「」，嵌套用『』。不用弯引号“”。
- 顿号「、」用于并列的词，逗号「，」用于并列的短语与分句。
- 破折号「——」占两个字宽，全篇不宜超过十处。
- 省略号「……」占两个字宽，不写成六个句点。
- 书名、期刊名用《》，篇名用〈〉。西文书刊名用斜体，不加书名号。
- 中西文之间不手动加空格，由 `xeCJK` 自动处理。

## 四、数字用法

按 GB/T 15835：

**用阿拉伯数字**：计量数值、统计数据、编号、年份月日、公式中的数
（`第 3 章`、`2026 年 9 月 3 日`、`增长 4.2%`、`图 1.2`）。

**用汉字数字**：概数与习惯用语、成语、约数、数字作语素
（`三四十年`、`十之八九`、`第一产业`、`四则运算`、`三次方程`）。

**其他约定**：

- 四位以上的数分节用逗号或不分节，全书统一，不用汉字「万」作单位混排
  （写 `12 000`，不写 `1.2 万`，除非引用的原始数据即以万为单位）。
- 百分数写作 `4.2%`，区间写作 `3%~5%`，不写「3~5%」。
- 数值与单位之间留一个空格，由 `siunitx` 处理：`\qty{4.2}{\percent}`、
  `\qty{20}{\wanyuan}`。货币与工时等中文单位已在 `common/macros-econ.tex`
  中声明，直接调用即可。

## 五、数学记号

按 GB 3102.11，这是国内出版审校最常挑出问题的一处。

**斜体**：变量、变动的参数、函数名中表示变量者、矩阵与向量的符号
（\(x\)、\(f\)、\(\alpha\)、\(A\)）。

**正体**：

- 数学常数与已定义的特殊数：自然常数 `\eu`、虚数单位 `\iu`、圆周率 `\pi`。
- 微分号：`\dif`，写作 \(\dif x\)，不写 \(dx\)。
- 函数名与算子：`sin`、`log`、`lim`、`max`、`Var`、`Cov`、`plim`——
  这些在 `common/` 的宏文件中已用 `\DeclareMathOperator` 声明，直接调用。
- 单位符号，以及作为标识的下标（\(x_{\max}\)、\(C_{\text{总}}\)）；
  作为变量的下标仍用斜体（\(x_i\)）。

**向量与矩阵**：用 `\vect{}` 与 `\mat{}`，排作黑斜体。经济学中的消费束等
用 `\bundle{}`。全书不得混用箭头记号 \(\vec{x}\)。

**公式排版**：

- 独立公式一律编号，即便正文未引用——便于课堂与习题引述。
- 公式是句子的一部分，句末该有句号就要有。
- 长公式在关系号或运算符**之前**断行，续行缩进对齐。
- 引用公式用 `\cref{eq:...}`，排作「式 (1.3)」。

## 六、图与表

- 图题在图下，表题在表上，两者都必须编号并在正文中至少引用一次。
  从未被正文提及的图表，说明它没有存在的必要。
- 表格一律用三线表（`\toprule` `\midrule` `\bottomrule`），不画竖线。
  确需分组时用 `\cmidrule`。
- 图题与表题是完整的说明，读者不看正文也应知道图里画的是什么。
  「图 1.1 生产可能性边界」不够，应写明坐标含义与各标记点的意思。
- 优先用 TikZ / pgfplots 直接绘图，源码与正文同库，便于日后修改与复现；
  只有扫描件、照片等才放进 `figures/`。
- 数据图必须注明数据来源与年份，来源著录进 `refs.bib`。
- 颜色须在黑白打印下仍可区分：靠线型、标记形状与灰阶承载信息，颜色只作辅助。

## 七、参考文献

- 全部文献著录于各学科目录下的 `refs.bib`，样式由 `biblatex-gb7714-2015` 统一处理，
  不要手写文献条目。
- 正文引用：叙述中用 `\textcite{key}`（排作「曼昆（2020）指出……」），
  括注中用 `\parencite{key}`。
- 教材、专著、期刊论文、学位论文、标准、网络资源的字段要求各不相同，
  条目必须填全 `author` `title` `year` `publisher`/`journaltitle` 等必备字段；
  英文文献加 `langid = {english}`。
- 引用他人的图、表、数据须在图题或表注中注明出处，并取得必要的授权。
  公开发布前须逐条复核。

## 八、动机与定位：三级机制

传统教材一上来就是定义、然后推导，学生不知道自己在学什么，也看不到整体框架。
本讲义用三级机制处理这个问题。三级都是**格式化的装置**，不是随笔发挥——
格位固定，正是为了防止动机段落退化成套话。

### 8.1 卷级：卷首地图

每卷开篇给一页「本卷地图」，说明本卷在基础数学中的位置、与前后卷的接口、
以及读完之后能进入哪些领域。

### 8.2 章级：开篇动机与章末去向

每章开篇必须包含四样：

1. **一个具体的失败案例**。不是抽象地说「有理数不够用」，而是给出
   \(1, 1.4, 1.41, 1.414, \dots\) 这样一个具体对象，说明它在哪里卡住。
2. **本章要做几件事**的编号清单。
3. **一张「本章结论在后续何处被用到」的表**，注明章号与用途。
4. **一条读法建议**，指明初读可略过什么。

每章末设一节「本章结论在更一般框架下的地位」，用表列出每条性质依赖的结构
与可推广的范围。

### 8.3 概念级：概念定位框

每章择三到五个**核心**概念，在其定义之前置一个 `concept` 环境，四格固定：

```latex
\begin{concept}{度量}
  \cwhy{...}    为何需要
  \crel{...}    与谁相关
  \cwhere{...}  位于何处
  \cdo{...}     能做什么
\end{concept}
```

四格的写法有硬约束：

- **为何需要**必须指向正文中**已经出现过**的一个具体障碍，并写出它的编号。
  不得写「为了更深刻地理解」「为后续内容作准备」这类无所指的话。
- **与谁相关**须说明它是谁的特例、谁的推广，或哪几个概念的共同抽象，
  并给出对应的章节号。
- **位于何处**须点名基础数学中的具体分支，以及谁在用它。
- **能做什么**须给出**具体的定理名或计算**。不得写「打下坚实基础」。
- 每格至多两句。

**最重要的一条：若四格中任何一格写不出具体内容，说明这个概念不值得单独立框，
应降级为正文中的一句引入语。** 这个框是筛子，不是装饰。一章里立五个以上的框，
通常意味着没有分清主次。

非核心的定义只需一句引入语，回答「为何需要」一问即可。

## 九、结构与篇幅

- 每章以 `keypoint` 要点框开篇，列三到五条，用完整句子写，不写成关键词罗列。
- 每章以习题收尾，习题数量不少于五道，难度递进。
- 章下设节，节下设小节，层级不超过三级。四级以上标题说明结构需要重新组织。
- 一节的正文以两到五页为宜。超过五页考虑拆分。
- 定义、定理必须给标签并在后文用 `\cref` 引用；从未被引用的定理，
  应考虑改写为正文中的一句话。

## 十、提交前自查清单

编译与格式：

- [ ] `make` 通过，两个学科的学生版与教师版均无报错。
- [ ] 日志中没有 `Undefined reference`、`Missing character`、`Overfull \hbox`
      超过 10pt 的警告。
- [ ] 学生版中确认不含任何解答文字。

内容：

- [ ] 每章开篇具备第八节所列的四样：具体失败案例、任务清单、去向表、读法建议。
- [ ] 概念定位框不超过五个，且四格全部指向具体对象，无「打下基础」一类的空话。
- [ ] 新出现的专业术语都用了 `\term`，且译名与全书一致。
- [ ] 所有图、表、公式都在正文中被引用过至少一次。
- [ ] 所有引用都在 `refs.bib` 中有对应条目，且字段完整。
- [ ] 每道习题都配了解答，解答不只给答案，还给出关键步骤与思路。

语言：

- [ ] 通读一遍，删去口语词、感叹号、无理由的价值判断。
- [ ] 检查第一节「杜绝 AI 腔与套话」中列出的各项，逐条排查。
- [ ] 数字用法与标点符合第三、四节的约定。
